# 全域快捷鍵模組規則 (v0)

## 1. 模組定位
集中管理所有鍵盤事件綁定，確保快捷鍵不與瀏覽器預設行為衝突，並實現統一分發。

## 2. 輸入與輸出
- **輸入**：監聽 `window` 的 `keydown` 與 `keyup` 事件。
- **輸出**：根據按鍵組合，轉換為 EventBus 上的語意化事件（如 `ACTION:COPY`, `ACTION:GROUP`）派發給各模組。

## 3. 邊界條件與例外處理
- **焦點保護**：當使用者正在「文字方塊 (Text Object)」內打字，或焦點在 UI 上的 `input` / `textarea` 時，必須**攔截並忽略**所有的單鍵快捷鍵 (如 V, H, B)，避免干擾打字。
- **快捷鍵清單對應**：
  - `Ctrl+C` / `Ctrl+V`：複製 / 貼上
  - `Ctrl+Z` / `Ctrl+Y`：復原 / 重做
  - `Ctrl+G`：組成群組
  - `Ctrl+Shift+G`：取消群組
  - `V`：選取工具
  - `H`：平移工具
  - `B`：畫筆工具
  - `Delete` / `Backspace`：刪除選中物件
