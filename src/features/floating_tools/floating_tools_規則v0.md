# 浮動快捷工具模組規則 (v0)

## 1. 模組定位
負責畫布右下角的「全螢幕 / 適應螢幕」、「圖層浮動面板預覽」、「留言/回饋」三大獨立快捷功能。該模組隸屬於 UI 輔助層，不直接修改畫布物件。

## 2. 輸入與輸出
- **全螢幕切換 (FullscreenTool.js)**：
  - 輸入：點擊按鈕。
  - 輸出：呼叫瀏覽器底層 `Fullscreen API`，並向 EventBus 發出 `UI:TOGGLE_FULLSCREEN` 事件，通知左右側邊欄套用隱藏樣式。
- **圖層浮動預覽 (QuickLayersTool.js)**：
  - 輸入：點擊按鈕。
  - 輸出：向 `CanvasEngine` 請求取得當前所有圖層陣列資料 (JSON 格式)，並在畫布右下角渲染彈出式 (Pop-over) 輕量圖層選單。
- **留言討論 (CommentTool.js)**：
  - 輸入：點擊按鈕。
  - 輸出：展開留言側邊面板，並載入假資料 (Mock Data) 進行展示。

## 3. 邊界條件與例外處理
- **層級保證 (Z-index)**：浮動工具列與彈出面板的 `z-index` 必須被設定在最高層級 (例如 Tailwind 的 `z-50`)，絕對不能被畫布上新增的大型圖片或物件遮擋。
- **全螢幕兼容性**：若使用者的瀏覽器不支援 Fullscreen API，則必須顯示 Toast 提示，並僅透過 CSS 隱藏側邊欄來達成「偽全螢幕」。
