# 圖層面板模組規則 (v0)

## 1. 模組定位
管理畫布上所有物件的 Z-index (上下層級) 關係與可視度、鎖定狀態，提供完整的圖層清單操作。

## 2. 輸入與輸出
- **輸入**：接收 `CANVAS:OBJECT_ADDED` / `MODIFIED` / `REMOVED` 以同步更新圖層列表。
- **輸出**：拖曳圖層項目時，觸發畫布物件的 `moveTo()` 方法以改變層級；點擊鎖定按鈕觸發物件 `selectable = false`。

## 3. 邊界條件與例外處理
- **底圖限制**：如果是「匯入的主題/底圖」，在圖層清單中必須強制固定在最底層，且不允許被拖曳改變順序。
