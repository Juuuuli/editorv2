# 屬性面板模組規則 (v0)

## 1. 模組定位
動態顯示當前畫布上被「選取 (Selected)」物件的詳細屬性，並提供修改介面（如文字大小、圖片亮度、群組按鈕）。

## 2. 輸入與輸出
- **輸入**：監聽 `CANVAS:OBJECT_SELECTED` 事件，接收該物件的 type 與參數物件。
- **輸出**：使用者在面板上調整數值後，即時向 `CanvasEngine` 呼叫 `object.set()` 並觸發重新渲染。

## 3. 邊界條件與例外處理
- **空狀態防呆**：當畫布上沒有選取任何物件時，面板必須顯示「請選擇畫布上的物件以編輯屬性」的提示，隱藏所有調整拉桿。
- **多選處理**：當接收到 Shift 多選的事件時，僅顯示「組成群組 / 取消群組」按鈕，隱藏個別屬性調整。
