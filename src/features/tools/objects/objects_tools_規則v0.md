# 加入新物件工具模組規則 (v0)

## 1. 模組定位
負責在畫布上生成新的實體物件：文字 (Text)、表格 (Table)、QR Code ( QRCode )、外部圖片 (External Image)。皆需拆分獨立檔案。

## 2. 輸入與輸出
- **輸入**：使用者點擊加入按鈕，或透過彈出視窗輸入參數 (如 QR Code 網址、表格欄列數)。
- **輸出**：建構 Fabric.js 或對應的物件實體，並觸發 `CANVAS:ADD_OBJECT` 將物件放置於畫布正中央。

## 3. 邊界條件與例外處理
- **防呆邊界**：新增的物件長寬若大於當前畫布尺寸，必須自動等比例縮放至畫布內緣大小的 80%。
- **QR Code 客製化**：產生 QR Code 後，物件預設必須包含 `canSaveToAssets: true` 屬性，以便屬性面板能顯示「存入素材庫」按鈕。
