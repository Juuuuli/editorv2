# 基本視圖工具模組規則 (v0.1)

## 1. 模組定位
負責最基礎的畫布操作，包含：選取 (Select)、平移 (Pan)、形狀 (Shape)、畫筆 (Brush)、放大縮小 (Zoom)。每個工具在資料夾中獨立為一個實體。

## 2. 輸入與輸出
- **輸入**：UI 按鈕點擊，以及畫布的 `mouse:down`, `mouse:move`, `mouse:up` 事件。
- **輸出**：呼叫 `CanvasEngine` 改變游標樣式、切換互動模式 (如 `isDrawingMode`)，或產生對應的圖形物件。

## 3. 狀態與邊界條件 (防呆)
- 任何時刻只能有一種互動模式處於 Active 狀態。切換工具時，必須先 Reset 其他工具的狀態。
- **畫筆模式**：必須設定好預設粗細與顏色 (手繪風格)。
- **平移模式 (Panning)**：不移動畫布內的物件，而是直接修改畫布的 `viewportTransform`，實現整個畫布視角的平移。
- **選取模式 (Selection / Region)**：在畫布上按住左鍵拖曳時，必須即時畫出一個「紅色虛線邊框」的矩形。放開左鍵後，該紅色虛線框必須實體化為一個可由使用者後續調整大小的 `fabric.Rect`，作為後續智慧辨識 (OCR) 或截圖的選取框。
