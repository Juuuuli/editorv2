# 系統說明書模組 (Manual) 規則 (v0)

## 1. 模組定位
提供使用者互動式翻頁手帳手冊 (`ManualPanel.js`) 與獨立樣式檔案 (`manual.css`)，呈現系統各項功能指引、快捷鍵一覽、智慧工具操作與 API 金鑰設定指南。

## 2. 核心架構與元件
- **檔案結構**：
  - `src/features/manual/ManualPanel.js`：說明書元件邏輯，管理 8 大章節內容、書籤標籤分頁切換、左右雙頁翻頁動畫與滾動提示。
  - `src/features/manual/manual.css`：手帳筆記本擬真外觀、活頁鐵環 (`.notebook-ring`)、翻頁動畫 (`flip-page`) 與響應式滾動條。
- **章節規劃 (Chapters)**：
  1. 系統簡介與快速上手
  2. 基礎工具與繪製
  3. 物件與多媒體操作 (文字/貼圖/表格/圖形)
  4. 智慧 AI 工具 (去背/生圖/擴展/物件消除)
  5. 畫布導覽與縮放控制
  6. 多頁管理與專案檔案 (匯入/匯出)
  7. 快捷鍵一覽表
  8. API 設定與金鑰管理指南

## 3. 輸入與輸出
- **輸入 (Events / Triggers)**：
  - 監聽頂部 Header 或設定視窗的「說明書」按鈕點擊事件。
  - 支援鍵盤快速鍵（如 `F1` 或按鈕綁定）開啟說明書。
  - 支援點擊目錄標籤、翻頁按鈕與左右方向鍵導覽。
- **輸出 (UI Actions)**：
  - 呈現擬真 3D 活頁手帳 Modal 彈窗與柔和背景遮罩。
  - 動態渲染左右雙頁圖文教學與程式碼範例。

## 4. 邊界條件與例外處理
- **內容超長保護**：雙頁內容超出高度時自動啟用獨立平滑滾動，並於底部顯示動態滾動提示 (`#notebook-left-scroll-hint`)。
- **按鈕狀態控制**：首頁時禁用「上一頁」，尾頁時禁用「下一頁」，書籤高亮自動同步。
- **獨立樣式隔離**：說明書所有 Class 以 `.notebook-*` 為前綴，避免與全局或特定主題樣式互相污染。
