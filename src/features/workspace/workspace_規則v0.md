# 雙工作區管理模組規則 (v0)

## 1. 模組定位
管理「圖片工作區」(單頁模式) 與「PPT/PDF 工作區」(多頁模式) 的切換、初始化及生命週期。

## 2. 輸入與輸出
- **輸入**：上方針對工作區切換的按鈕點擊事件，以及檔案匯入事件。
- **輸出**：向 UI 發出 `WORKSPACE:MODE_CHANGED` 事件，控制縮圖面板的顯示/隱藏，並初始化對應的 Canvas 實體。

## 3. 邊界條件與例外處理
- **比例鎖定**：一旦接收到 `EVENT:FILE_IMPORTED`，必須鎖定頂部的比例切換按鈕。
- **切換保護**：若工作區已有未儲存的畫布內容，在切換工作區模式前必須跳出 `Window.confirm()` 警告避免資料遺失。
