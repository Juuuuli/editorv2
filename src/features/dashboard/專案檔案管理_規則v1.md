# 專案檔案管理模組 (Dashboard & Storage) 規則 (v1)

## 1. 模組簡介
本模組提供使用者首頁儀表板視圖 (`DashboardManager.js`) 與本機持久化儲存引擎 (`ProjectStorageEngine.js`)，支援多專案並行、本機資料持久化、防抖自動存檔與檔案匯入匯出。

## 2. 核心檔案職責
- `src/features/storage/ProjectStorageEngine.js`：
  - 封裝原生 IndexedDB (`EditorV2_ProjectsDB` -> `projects`)。
  - 提供 `getAllProjects()`, `getProject(id)`, `saveProject(data)`, `deleteProject(id)`, `duplicateProject(id)`, `exportProjectFile(id)`, `importProjectFile(file)`, `createBlankProject(options)`。
- `src/features/dashboard/DashboardManager.js`：
  - 負責首頁專案網格、搜尋篩選、新增專案模板彈窗、專案卡片選單。
  - 提供 `openProject(projectId)` 與 `closeProjectToDashboard()`。
  - 監聽畫布異動，進行防抖 (Debounce 800ms) Auto-Save 並更新儲存狀態標記。

## 3. 通訊與事件
- `PROJECT:IMPORTED`：通知縮圖面板與畫布載入新專案的多頁狀態。
- `CANVAS:DIRTY` / `PAGE:SWITCH` / `PAGE:ADD` / `PAGE:DELETE` / `PAGE:COPY`：觸發 Auto-Save 寫入 IndexedDB。
