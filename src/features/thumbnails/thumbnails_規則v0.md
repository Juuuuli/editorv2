# 縮圖面板模組規則 (v0)

## 1. 模組定位
專屬於「PPT/PDF 工作區」的右側多頁預覽面板，提供新增、刪除、複製與快速切換頁面的功能。

## 2. 輸入與輸出
- **輸入**：來自 `CanvasEngine` 的當前頁面截圖 (base64)，以及使用者的點擊/新增/刪除操作。
- **輸出**：向 EventBus 發送 `PAGE:SWITCH`、`PAGE:ADD`、`PAGE:DELETE` 事件，並更新 UI 選中狀態。

## 3. 邊界條件與例外處理
- **隔離原則**：若當前處於「圖片工作區」，此模組必須被完全隱藏且不實例化，避免記憶體浪費與意外觸發。
- **最少頁面限制**：不可刪除最後一頁，當只剩一頁時，「刪除」按鈕必須處於 Disabled 狀態。
