# 狀態存儲模組規則 (v0)

## 1. 模組定位
負責與瀏覽器底層 IndexedDB 或 LocalStorage 溝通，實現「自動暫存進度」與防止意外關閉的資料保護機制。

## 2. 輸入與輸出
- **輸入**：接收畫布的變更事件 `CANVAS:STATE_CHANGED`，以及系統初始化時的載入請求。
- **輸出**：將 JSON 序列化存入 IndexedDB；初始化時若發現暫存資料，跳出提示詢問是否還原進度。

## 3. 邊界條件與例外處理
- **防抖機制 (Debounce)**：為避免頻繁寫入資料庫造成瀏覽器卡頓，自動儲存必須加上 3 秒的防抖。即「使用者停止操作 3 秒後」才執行寫入。
- **配額處理 (Quota Exceeded)**：若 IndexedDB 容量不足，必須透過 EventBus 觸發警告 Toast 通知使用者清理空間。
