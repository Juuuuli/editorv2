# 歷史紀錄管理模組規則 (v0)

## 1. 模組定位
負責監控畫布狀態變更，提供「復原 (Undo)」與「重做 (Redo)」機制的堆疊 (Stack) 管理。

## 2. 輸入與輸出
- **輸入**：接收畫布物件的實質變更事件（新增、刪除、位移、縮放、屬性修改），以及 UI 點擊或快捷鍵 `Ctrl+Z` / `Ctrl+Y`。
- **輸出**：呼叫 `CanvasEngine.loadFromJSON()` 載入特定的歷史節點狀態，並更新 UI 上的 Undo/Redo 按鈕 Disabled 狀態。

## 3. 邊界條件與例外處理
- **堆疊上限**：為防止記憶體溢出 (OOM)，歷史堆疊上限固定為 50 步。超過 50 步時自動捨棄最舊的紀錄。
- **無效動作過濾**：單純的「選取 (Select)」、「取消選取」或「平移視角 (Pan)」不可寫入歷史紀錄。僅儲存會影響輸出的實質畫面變更。
