# 🌙 深色極客 (Dark Geek / Midnight Studio) 風格指令 V2

> **⚠️ 遵循聲明**
> 開發此主題時，必須同時遵守 [全系統風格指令總綱 V2](../風格指令v2.md) 中的所有禁止事項與互動規範。本文件專注於定義 Dark Geek 主題的嚴謹 Design Tokens 與專屬 Component Blueprints。

## 1. 風格定位與設計哲學 (V2 升級版)
- **核心定位**：高資料密度、零干擾、專業開發者友善的賽博夜間控制台。
- **設計哲學升級**：在保留黑曜夜空與電光霓虹配色的同時，**全面拔除上一版厚重且干擾視覺的立體陰影與發光暈**。改以 `0.5px` 的極細發光邊框來取代，以維持大面積長時間使用的專業度。

---

## 2. 決定性色彩調色盤 (Strict Design Tokens)

**絕對禁止**在此主題內使用非以下定義之顏色或 Tailwind 預設色。所有顏色應對應到 CSS 變數：

| CSS 變數 (Token) | Hex 色碼 | 嚴格使用場景 |
| :--- | :--- | :--- |
| `--bg-app` | `#090d16` | **全域唯一**最底層背景色（外層視窗、底層） |
| `--bg-panel` | `#0f172a` | 面板、側欄、頂部導覽列底色 |
| `--bg-surface` | `#1e293b` | 列表、卡片、浮層容器的背景色 |
| `--border-hairline` | `rgba(56, 189, 248, 0.15)` | **0.5px** 專用！所有區塊分割線、卡片外框 |
| `--border-glow` | `rgba(99, 102, 241, 0.4)` | 僅限 Input Focus 或 Active 狀態的邊框 |
| `--accent-primary` | `#38bdf8` | 主按鈕背景、當前焦點、游標 (Cyan) |
| `--status-success` | `#34d399` | **僅限**成功、啟用、完成狀態 (Emerald) |
| `--status-danger` | `#f43f5e` | **僅限**刪除、錯誤提示 (Rose) |
| `--text-primary` | `#f8fafc` | 主要標題、主按鈕文字（高對比白） |
| `--text-muted` | `#64748b` | 次要輔助說明、不重要之資訊 |

---

## 3. 視覺限制指令 (Visual Constraints)

### 3.1 陰影與發光 (Strict Shadow Rules)
- **禁止**：標準按鈕、專案卡片、輸入框**絕對不可**使用 `box-shadow`。
- **允許**：Drawer (側邊抽屜) 與 Modal (彈窗) **必須**包含外發光 `box-shadow: 0 0 30px rgba(99,102,241,0.1)` 創造浮層感。

### 3.2 邊框與字體 (Borders & Typography)
- **邊框粗細**：除特例外，所有卡片邊框強制為 `0.5px` (或 `border-width: 1px; border-color: var(--border-hairline)` 以達視覺 0.5px 效果)。
- **等寬字體**：表格數字、ID、程式碼標籤**必須**使用等寬字體 (`ui-monospace, monospace`)。

---

## 4. 元件標準骨架 (Component Blueprints)

若需要實作專案卡片，請嚴格遵守以下 HTML 結構，以確保所有 Agent 產出的 DOM 結構一致：

```html
<!-- [Blueprint] Dark Geek Card -->
<div class="relative bg-[var(--bg-surface)] border-[0.5px] border-[var(--border-hairline)] rounded-[12px] p-5 overflow-hidden transition-colors hover:border-[var(--accent-primary)]">
    <!-- Header -->
    <div class="flex items-center justify-between mb-2">
        <h3 class="text-[var(--text-primary)] text-[15px] font-bold">卡片標題</h3>
        <!-- Action Area (e.g. settings icon) -->
    </div>
    <!-- Body -->
    <div class="text-[var(--text-muted)] text-[12px]">
        相關描述與資料...
    </div>
</div>
```

## 5. CSS 擴充與選擇器準則
- 在 `src/themes/dark-geek/index.css` (或其他關聯檔) 中，所有樣式宣告必須包裹在 `[data-theme="dark"]` 選擇器之下。
