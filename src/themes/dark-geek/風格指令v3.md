# 可直接貼給 AI 的提示詞 (Dark Geek)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要用以下設計風格產出介面。這是一套**專為長時間沉浸式工作設計的深色極客**風格（賽博夜間控制台），請嚴格遵守。

## 色彩 (Design Tokens)
禁止自行發明色票，請遵守以下設定：
- 全域背景 (`--bg-app`)：`#090d16`（極深黑）
- 側欄/面板 (`--bg-panel`)：`#0f172a`（深藍黑）
- 卡片/表面 (`--bg-surface`)：`#1e293b`
- 邊框 (`--border-hairline`)：`rgba(56, 189, 248, 0.15)` 或 `1px solid #334155`
- 焦點邊框 (`--border-glow`)：`rgba(99, 102, 241, 0.4)`（僅限 Input Focus 或 Active 狀態）
- 主文字 (`--text-primary`)：`#f8fafc`（高對比白）
- 輔助文字 (`--text-muted`)：`#64748b`（次要灰白）
- 重點點綴色 (`--accent-primary`)：青色 `#38bdf8` 或是低調紫色 `#c084fc`
- 狀態色：成功 `#34d399`、危險 `#f43f5e`

## 三個不可妥協的特徵
1. **嚴格管制陰影與發光**：標準按鈕、專案卡片、輸入框**絕對不可**使用 `box-shadow`。嚴禁過去深色模式濫用的擴散霓虹光暈。僅有側邊抽屜 (Drawer) 與彈窗 (Modal) **必須**包含外發光 `box-shadow: 0 0 30px rgba(99,102,241,0.1)` 以創造浮層感。
2. **暗色階層明確切割**：利用背景的極深黑（`#090d16`）與卡片的深灰藍（`#1e293b`）來切分區塊，邊框強制為 `0.5px` 極細發光邊框。
3. **等寬字體與柔和高亮**：表格數字、ID、程式碼標籤**必須**使用等寬字體 (`ui-monospace, monospace`)。當需要高亮背景時，使用極低透明度的色塊（如 `rgba(56, 189, 248, 0.15)`），不要使用高彩度實心色塊。

## 組件藍圖：卡片 (Dark Geek Card)
請嚴格遵守以下 HTML 結構產出卡片：
```html
<div class="relative bg-[var(--bg-surface)] border-[0.5px] border-[var(--border-hairline)] rounded-[12px] p-5 overflow-hidden transition-colors hover:border-[var(--accent-primary)]">
    <!-- Header -->
    <div class="flex items-center justify-between mb-2">
        <h3 class="text-[var(--text-primary)] text-[15px] font-bold">卡片標題</h3>
    </div>
    <!-- Body -->
    <div class="text-[var(--text-muted)] text-[12px]">
        相關描述與資料...
    </div>
</div>
```
