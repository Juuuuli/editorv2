# 可直接貼給 AI 的提示詞 (Dark Geek)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），
接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要用以下設計風格產出後台管理介面。這是一套**黑曜夜空、霓虹光暈、賽博龐克工程師與夜間專注工作台**風格，請嚴格遵守。

## 色彩

中性色（極深藍黑基底，不要用髒灰）：
- 頁面底 `--bg-app` `#090d16`／側欄或工具箱底 `--bg-panel` `#0b1120`／卡片底 `--bg-surface` `#1e293b`
- 頂部 Header `--bg-header`：`#0f172a`
- 邊框 `--border-base`：`#334155`（基礎線 1px ~ 1.5px）
- 發光邊框 `--border-glow`：`rgba(99, 102, 241, 0.4)`
- 文字 `--text-primary` `#f8fafc`（高亮白）／`--text-secondary` `#94a3b8`（次要冷灰）／`--text-muted` `#64748b`（暗灰）

語意色（高飽和度霓虹色）：
- 主焦點 / 亮點 `--accent-cyan`：`#38bdf8`（電光青）
- 主按鈕 / 強調 `--accent-indigo`：`#6366f1`（靛藍霓虹）
- 成功 / 儲存 `--accent-emerald`：`#34d399`（翡翠綠）
- 特殊工具 `--accent-purple`：`#c084fc`

規則：告別低對比度的髒灰，採用極深藍黑基底搭配高飽和度的電光色。

## 三個不可妥協的特徵

1. **霓虹發光與深邃陰影**：卡片外圍要有深邃陰影 `0 10px 30px -5px rgba(2,6,23,0.8)`，按鈕或 Hover 狀態需帶有霓虹微光 `0 0 16px rgba(56,189,248,0.25)`。
2. **深藍黑夜空底色**：全站不可使用純黑 `#000000`，必須保持科技藍黑色調。
3. **組件漸層感**：登入彈窗或核心按鈕常帶有科技漸層（例如青藍漸層），並有發光外層 `0 0 40px rgba(99,102,241,0.25)`。

## 字型與尺度

字型：介面文字使用 `Inter, system-ui, sans-serif`；程式碼與標籤強烈建議使用等寬字 `ui-monospace, Consolas, monospace`。基準 14px / 1.5。
標題字重必須極粗：`800 / 900 (Extra Bold / Black)`。

圓角：按鈕 `10px ~ 12px` / 浮層卡片 `14px ~ 18px`。

## 版面

頂欄 56px（#0f172a），頁面背景可帶有極深漸層 `radial-gradient(circle at 50% 0%, #0f172a 0%, #090d16 100%)`。畫布工作區輔助線採用電光青藍微光 `rgba(56,189,248,0.3)`。

## 元件

- **按鈕**：核心按鈕為深曜石底色搭配霓虹圖示色；Hover 時發光陰影。
- **卡片**：深邃背景 `#1e293b`，Hover 時向上浮動 2px，邊框亮起 `#6366f1` 霓虹光暈。
- **狀態標籤**：深色背景中點亮螢光色，增加科技感。
- **彈窗／抽屜**：彈窗打斷、抽屜輔助（右側滑入）。彈窗周圍強烈發光。
- **表單聚焦**：聚焦時不只變換邊框顏色，邊框必須亮起 Neon Glow 發光外框。

## 互動慣例（務必遵守，這比視覺更能決定成品像不像）

1. **層級式操作**：不要一頁攤開所有資料與設定。第一層只給列表，點選某列後從**右側抽屜**展開該筆的詳細設定。一次只面對一個對象。
2. **用提示框解釋取捨**：寫「為什麼這樣設計、不這樣會怎樣」，格式為「**取捨標題：**做法 —— 因為 A，若改成 B 會導致 C」。
3. **破壞性操作要防呆**：擋住會讓系統無法挽回的狀態，並說明原因。
4. **數字由資料算出**：統計數字、徽章一律即時計算，不可寫死。

## 文案風格

專業極客感。主動標示限制與取捨，講因果不只講規則。錯誤訊息要具體。

## 無障礙

彈窗與抽屜要 `role="dialog"`、`aria-modal="true"`；純圖示按鈕要 `aria-label`；動畫尊重 `prefers-reduced-motion`。
