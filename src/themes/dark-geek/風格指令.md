# 🌙 深色極客 (Dark Geek / Midnight Studio) 風格指令

## 1. 風格定位與設計哲學
- **核心定位**：黑曜夜空、霓虹光暈、賽博龐克工程師與夜間專注工作台。
- **設計哲學**：告別低對比度的髒灰，採用極深藍黑基底 (`#090d16`) 搭配高飽和度的電光青 (`#38bdf8`)、靛藍霓虹 (`#6366f1` / `#818cf8`) 與翡翠綠 (`#34d399`)，營造極具未來感的深色極客工作環境。

## 3. 排版與邊框陰影規範

### 3.1 字體 (Typography)
- **程式碼與標籤**：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`
- **介面文字**：`Inter, system-ui, -apple-system, sans-serif`
- **標題字重**：`800 / 900 (Extra Bold / Black)`

### 3.2 圓角與陰影 (Border Radius & Shadows)
- **面板圓角**：`14px ~ 18px`
- **按鈕圓角**：`10px ~ 12px`
- **標準霓虹微光**：`box-shadow: 0 0 16px rgba(56, 189, 248, 0.25)`
- **主要發光按鈕**：`box-shadow: 0 0 20px rgba(6, 182, 212, 0.35)`
- **卡片深邃外陰影**：`box-shadow: 0 10px 30px -5px rgba(2, 6, 23, 0.8)`

## 4. 各功能區塊風格指令

### 4.1 頂部導覽列 (Header)
- 背景使用 `#0f172a`，下方加 `1px solid #334155` 邊框。
- 專案標題 Hover 時文字轉為 `#818cf8`，邊框呈現霓虹青藍。
- 各操作按鈕（復原、重做、匯入、匯出）採用深曜石底搭配獨立霓虹圖示色。

### 4.2 專案儀表板 (Dashboard)
- 頁面背景採極深漸層 `radial-gradient(circle at 50% 0%, #0f172a 0%, #090d16 100%)`。
- 專案卡片 Hover 時向上浮動 2px，邊框亮起 `#6366f1` 霓虹光暈。
- 「建立新專案」按鈕採用電光青藍漸層背景。

### 4.3 畫布工作區 (Canvas & Workspace)
- 畫布視圖外部襯底採用 `#090d16`。
- 輔助對齊標尺與格線採用電光青藍微光 (`rgba(56, 189, 248, 0.3)`)。
- 選取中物件的控制手柄呈現 Cyan 外框與發光陰影。

### 4.4 登入與身分認證 (Auth Modal)
- 登入彈窗邊框帶有 `1.5px solid rgba(99, 102, 241, 0.4)`。
- 外層發光 `0 0 40px rgba(99, 102, 241, 0.25)`。
- 登入按鈕採用青藍科技漸層 `linear-gradient(135deg, #4f46e5 0%, #06b6d4 100%)`。

---

## 5. CSS 擴充與選擇器準則
- 所有深色極客專屬樣式必須掛載在 `[data-theme="dark"]` 或 `body.theme-dark` 作用域下。
- 嚴禁污染全域預設樣式；使用 `!important` 確保覆蓋 Tailwind 預設類別。
