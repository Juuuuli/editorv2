# 經典手繪 (Light Sketch) - 風格指令 (V1)

## 核心精神
隨性、溫暖、插畫感。不追求絕對對齊與死板的線條。

## 樣式特徵
1. **雙線邊框**: 卡片與按鈕需使用 `border-radius: 255px 15px 225px 15px/15px 225px 15px 255px;` 來製造手繪不規則感。
2. **顏色**: 邊框統一使用 `#334155`，背景為白色。
3. **陰影**: 按鈕需帶有實體的投影 `box-shadow: 2px 2px 0px rgba(51, 65, 85, 0.15)`。
4. **背景**: 畫布背景要有方格紙網點效果。

## 寫法規範 (V1)
- 可以自由使用 Tailwind classes 來組裝畫面。
- 不強制抽離 Design Tokens。
- 如果需要手繪邊框，直接給 HTML 元素加上 `sketch` 或 `sketch-btn` class 即可。
