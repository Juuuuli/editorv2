# 經典手繪 (Light Sketch) - 風格指令 v2

## 核心精神 (Design Philosophy)
手繪感不代表程式碼可以隨便寫！V2 嚴格規範手繪邊框的寫法，並透過明確的 CSS 設定鎖死色彩與尺寸。禁止在 HTML 內隨意寫死 inline-style。

## Design Tokens (嚴格色票與變數)
開發時請務必遵循以下設定，禁止自行發明色票：
- `--sketch-border`: `#334155` (主要的粗邊框色)
- `--sketch-bg`: `#ffffff` (卡片背景色)
- `--sketch-shadow`: `rgba(51, 65, 85, 0.15)` (常態實體陰影)
- `--sketch-shadow-hover`: `rgba(51, 65, 85, 0.25)` (懸停實體陰影)

## Component Blueprints (組件藍圖)

### 1. 手繪卡片 (Sketch Panel)
禁止自行用 `rounded-xl` 或 `border-solid` 等 Tailwind 類別去拼湊手繪卡片。
**必須使用預定義類別**：`<div class="sketch">` 或 `<div class="sketch-panel">`。
- CSS 層已定義好精確的不規則圓角：`border-radius: 255px 15px 225px 15px/15px 225px 15px 255px;`
- Hover 時的不規則圓角交替：`border-radius: 15px 255px 15px 225px/225px 15px 255px 15px;`

### 2. 手繪按鈕 (Sketch Button)
**必須使用**：`<button class="sketch-btn">`。
- CSS 層已定義自帶實體陰影與點擊下壓動畫 (`transform: translateY(-1px)`).
- 禁用狀態請使用 `.sketch-btn-disabled`，邊框與字體會轉為 `#94a3b8`，並關閉游標事件。

### 3. 工具提示框 (Tooltip)
**必須使用**：`<div class="sketch-tooltip">`。
- 背景為深色 `#1e293b`，帶有與整體一致的手繪不規則外框。

## 嚴格防呆規則 (Strict Constraints)
1. **禁止覆寫邊框**: 不允許在 `.sketch` 元素上額外加上 `border-blue-500` 或 `rounded` 等 Tailwind 覆寫類別，這會破壞手繪形狀。
2. **層級與作用域管理**: 
   - 由於此風格被設定為**系統基底預設風格 (Default Base)**，它的樣式沒有被加上 `[data-theme="light"]` 的強制作用域限制。
   - **這是刻意設計的**，為的是確保其他現代風格 (例如 Pro Slate 或 Dark Geek) 能以此為基底進行正確的覆寫 (Override)。請勿隨意替這些基底類別加上 Scope。
