# 可直接貼給 AI 的提示詞 (Settings Modal)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要產出一個系統設定與金鑰保險箱彈窗 (Settings & API Vault Modal)。請嚴格遵守以下佈局與 UX 規範。

## 模組定位與架構原則
根據 V3 總綱「彈窗打斷、抽屜輔助」的原則，全域設定這類操作通常需謹慎管理版面空間：
- **絕對尺寸限制**：若是維持置中 Modal 設計，彈窗的寬度最大 `760px`，高度最大 `540px` (最大不可超過 `95vw × 90vh`)，**絕對禁止**設定面板因內容過多而無限長高破壞版面。

## 內部捲動機制 (Scroll Control)
`Header` 必須是固定的 (Shrink-0)，只有中段的主內容區與側邊分頁欄允許 `overflow-y-auto`。

## 組件藍圖 (Settings Blueprint)
請嚴格使用以下結構產出彈窗：
```html
<div class="fixed inset-0 z-50 flex items-center justify-center bg-black/40 backdrop-blur-sm" role="dialog" aria-modal="true">
    <div class="theme-settings-container w-full max-w-[760px] h-[540px] max-h-[90vh] flex flex-col rounded-xl overflow-hidden shadow-[0_20px_60px_rgba(0,0,0,0.15)] bg-[var(--bg-surface)] border-[0.5px] border-[var(--border-hairline)]" data-theme="inherit">
        <!-- Header (固定) -->
        <header class="h-[56px] shrink-0 px-6 border-b-[0.5px] border-[var(--border-hairline)] flex items-center justify-between bg-[var(--bg-panel)]">
            <h2 class="text-[16px] font-bold text-[var(--text-primary)]">系統設定</h2>
            <button class="close-btn text-[var(--text-muted)] hover:text-[var(--status-danger)]"><i class="fas fa-times"></i></button>
        </header>
        <!-- Main Content Area (可捲動) -->
        <div class="flex-1 overflow-hidden flex">
            <!-- 側邊分頁導覽 -->
            <nav class="w-[200px] h-full overflow-y-auto border-r-[0.5px] border-[var(--border-hairline)] bg-[var(--bg-panel)] p-3">
                <button class="w-full text-left px-3 py-2 rounded-lg text-[13px] font-bold bg-[var(--accent-primary)] text-[var(--bg-surface)] mb-1">外觀主題</button>
                <button class="w-full text-left px-3 py-2 rounded-lg text-[13px] text-[var(--text-muted)] hover:bg-[var(--bg-surface)]">API 金鑰</button>
            </nav>
            <!-- 設定細項 (可捲動) -->
            <div class="flex-1 h-full overflow-y-auto p-6 bg-[var(--bg-surface)]">
                <!-- 內容... -->
            </div>
        </div>
    </div>
</div>
```

## 金鑰保險箱安全防呆 (API Vault Anti-Errors)
- **遮蔽顯示**：API Key 預設必須以 `••••••••` 遮蔽，附帶切換顯示/隱藏的按鈕。
- **儲存確認**：金鑰更新後，必須在按鈕旁顯示 `--status-success` 顏色的 `✓ 已儲存` 提示，**禁止使用 `alert()`**。
- **Note 提示**：在輸入框下方，必須掛載標準的 Note 提示框，警告：「金鑰僅儲存於本地瀏覽器，清除 Cache 將導致金鑰遺失。」
