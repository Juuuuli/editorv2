# ⚙️ 系統設定與金鑰保險箱彈窗 (Settings & API Vault Modal) 風格指令 V2

> **⚠️ 遵循聲明**
> 此為共用設定面板指令。必須同時遵守 [全系統風格指令總綱 V2](../風格指令v2.md) 中的所有禁止事項。

## 1. 模組定位與架構升級 (V2)
- **核心定位**：全域系統設定、外觀主題切換中樞。
- **UX 互動升級 (Modal to Drawer Transition)**：
  - 根據 V2 總綱「彈窗打斷、抽屜輔助」的原則，系統設定若超過 5 個設定項目或包含複雜的樹狀分頁，**應考慮將其從置中 Modal 升級為從右側滑出的 Drawer (抽屜)**。
  - 若維持 Modal 設計，則必須嚴格遵守下方定義的尺寸限制，絕不可覆蓋全螢幕。

---

## 2. 嚴格尺寸與骨架規範 (Dimension Blueprints)

**絕對禁止**設定面板因內容過多而無限長高，破壞版面。

### 2.1 固定的最大尺寸限制
- **系統設定彈窗**：寬 `760px`，高 `540px` (最大寬高不可超過 `95vw × 90vh`)。
- **內部捲動機制**：`Header` 與 `Footer` 必須是 Fixed 或 Sticky，僅中段內容區 `Body` 允許 `overflow-y-auto`。

### 2.2 設定面板標準骨架 (Settings Blueprint)
```html
<div class="fixed inset-0 z-50 flex items-center justify-center bg-black/40 backdrop-blur-sm" role="dialog" aria-modal="true">
    <div class="theme-settings-container w-full max-w-[760px] h-[540px] max-h-[90vh] flex flex-col rounded-xl overflow-hidden shadow-floating bg-[var(--bg-surface)] border-[0.5px] border-[var(--border-hairline)]" data-theme="inherit">
        
        <!-- Header (固定) -->
        <header class="h-[56px] shrink-0 px-6 border-b-[0.5px] border-[var(--border-hairline)] flex items-center justify-between bg-[var(--bg-panel)]">
            <h2 class="text-[16px] font-bold text-[var(--text-primary)]">系統設定</h2>
            <button class="close-btn text-[var(--text-muted)] hover:text-[var(--status-danger)]"><i class="fas fa-times"></i></button>
        </header>
        
        <!-- Main Content Area (可捲動) -->
        <div class="flex-1 overflow-hidden flex">
            <!-- 側邊分頁導覽 -->
            <nav class="w-[200px] h-full overflow-y-auto border-r-[0.5px] border-[var(--border-hairline)] bg-[var(--bg-panel)] p-3">
                <button class="w-full text-left px-3 py-2 rounded-lg text-[13px] font-bold bg-[var(--accent-primary)] text-white mb-1">外觀主題</button>
                <button class="w-full text-left px-3 py-2 rounded-lg text-[13px] text-[var(--text-muted)] hover:bg-[var(--bg-surface)]">API 金鑰</button>
            </nav>
            
            <!-- 設定細項 (可捲動) -->
            <div class="flex-1 h-full overflow-y-auto p-6 bg-[var(--bg-surface)]">
                <!-- 內容... -->
            </div>
        </div>
        
    </div>
</div>
```

## 3. 金鑰保險箱安全防呆 (API Vault Anti-Errors)
在設定 API Key 時，屬於高風險操作，必須使用嚴謹的視覺回饋：
- **遮蔽顯示**：API Key 預設必須以 `••••••••` 遮蔽，附帶一個切換顯示/隱藏的小眼睛 Icon。
- **儲存確認**：金鑰更新後，必須在按鈕旁顯示 `--status-success` 顏色的 `✓ 已儲存` 提示，而不是跳出惱人的 <code>alert()</code>。
- **Note 提示**：在輸入框下方，必須掛載標準的 Note 提示框，警告：「金鑰僅儲存於本地瀏覽器，清除 Cache 將導致金鑰遺失。」
