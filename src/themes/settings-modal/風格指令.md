# ⚙️ 系統設定彈窗 (Settings Modal) 風格指令

## 1. 模組定位與設計哲學
- **核心定位**：全域系統設定、外觀主題切換、金鑰保險箱與畫布規格配置中樞。
- **設計哲學**：採用沉穩冷靜的 **Dark Slate 現代設定中樞風格**，在任何主題下開啟設定時皆維持穩定、清晰、高對比度的配置介面；同時內建 **4 大主題獨立預覽沙盒**，確保使用者在挑選外觀時能獲得 100% 精準的主題真實縮圖。

---

## 2. 視窗尺寸與佈局規範

| 規範項目 | 設定值 | 說明 |
| :--- | :--- | :--- |
| **彈窗寬度** | `max-w-4xl (896px)` | 寬敞雙欄/多卡片並排配置 |
| **最大高度** | `max-h-[90vh]` | 避免超出視窗 |
| **內部佈局** | `flex flex-col` | 固定標題 Header + 滾動內容 Body + 固定底部 Footer |
| **滾動區域** | `overflow-y-auto` | 內容過長時滾動，禁止彈窗本身產生外層跳動 |
| **背景色** | `#0f172a / #1e293b` | 專業深色極客 / 深石墨雙層面板 |

---

## 3. 外觀主題預覽沙盒隔離規範 (Theme Preview Sandbox)

在「外觀與主題」設定分頁中，提供 4 款主題卡片，各卡片內部樣式獨立隔離：

1. **經典手繪預覽卡片**：
   - 卡片背景：純白 `#ffffff`
   - Header：亮黃 `#fef08a`，文字深炭黑 `#0f172a`
   - 邊框與按鈕：手繪粗黑邊與立體硬陰影
2. **深色極客預覽卡片**：
   - 卡片背景：黑曜夜空 `#090d16`
   - Header：深藍夜空 `#0f172a`，電光青 `#38bdf8`
   - 邊框與按鈕：霓虹青藍發光框
3. **專業冷灰預覽卡片**：
   - 卡片背景：純淨白底 `#ffffff`
   - Header：深石墨冷灰 `#1e293b`，高對比純白字
   - 邊框與按鈕：1px 細微冷灰邊框與幾何 8px 倒角
4. **復古文青預覽卡片**：
   - 卡片背景：羊皮紙底 `#f5eedc`
   - Header：深胡桃木 `#36261c`，米白襯線字
   - 邊框與按鈕：皮革棕雙線外框與焦糖琥珀封蠟印章按鈕

---

## 4. 互動與反饋指令
- **選取中高亮**：當前啟用的主題卡片外框加上 `ring-2 ring-indigo-500` 與 `👑 使用中` 徽章。
- **即時預覽**：點擊卡片後立即透過 EventBus 發送 `THEME:SET`，全系統即時無縫重繪，無須重新整理頁面。
