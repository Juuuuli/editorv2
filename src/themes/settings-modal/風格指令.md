# ⚙️ 系統設定與金鑰保險箱彈窗 (Settings & API Vault Modal) 風格指令

## 1. 模組定位與設計原則
- **核心定位**：全域系統設定、外觀主題切換、金鑰保險箱與畫布規格配置中樞。
- **長寬固定原則 (Fixed Dimensions)**：
  - 系統設定彈窗：`760px × 540px` (最大寬高 `95vw × 90vh`)
  - 金鑰保險箱彈窗：`580px × 560px` (最大寬高 `95vw × 90vh`)
  - 尺寸固定不因分頁內容多寡縮放，超出高度由中段內容區獨立垂直滾動 (`overflow-y-auto`)。
- **風格隨動原則 (Dynamic Theme Adaptability)**：彈窗外觀不再鎖死單一深色，而是即時隨著全域主題 (`[data-theme]`) 動態變換對應質感。

## 3. 主題預覽卡片沙盒隔離 (Theme Sandbox)
- 設定彈窗「主題與風格」分頁內的 4 款主題卡片，保持獨立的沙盒縮圖顏色，方便使用者預覽各主題樣式。
- 點擊卡片觸發 `THEME:SET`，系統即時平滑變換全站外觀，彈窗本體亦同步無縫變色。
