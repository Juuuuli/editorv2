# 可直接貼給 AI 的提示詞 (Pro Slate)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要用以下設計風格產出介面。這是一套**現代俐落、適合高密度數據閱讀的專業後台**風格，請嚴格遵守。

## 色彩 (Design Tokens)
禁止自行發明色票，請遵守以下設定：
- 全域背景 (`--bg-app`)：`#e2e8f0`（冷灰色）
- 面板/側邊欄 (`--bg-panel`)：`#f1f5f9`
- 卡片/主要內容區 (`--bg-surface`)：`#ffffff`（純淨白）
- 頂部 Header：`#1e293b`（深石墨黑，創造頂部視覺重量）
- 邊框 (`--border-hairline`)：極細實線 `rgba(15, 23, 42, 0.1)` 或 `#cbd5e1`
- 主要文字 (`--text-primary`)：`#0f172a`（深炭黑）
- 輔助文字 (`--text-muted`)：`#64748b`
- 主按鈕 (`--accent-primary`)：`#0f172a`（黑底白字），或高亮狀態 `#0284c7`（科技藍）
- 狀態色：成功 `#059669`、危險 `#dc2626`

## 三個不可妥協的特徵
1. **零陰影原則與極細邊界切割**：所有卡片 (`.theme-card`) 與一般按鈕 (`.theme-btn`) **絕對不可**有 `box-shadow`。僅依賴 `0.5px` 或 `1px` 細線 `#cbd5e1` 分割區塊。僅有浮層（抽屜/彈窗）允許使用極淡陰影 `0 20px 60px rgba(0,0,0,0.15)`。
2. **禁止全大寫氾濫**：除非是 Table Header (表頭) 或極小的 Tag，一般文字禁止使用 `uppercase`。
3. **冷靜理性的高頻操作環境**：嚴禁使用任何鮮豔的螢光色大面積鋪底，亮色（如科技藍）僅限用於最核心的行動按鈕。

## 互動特效與排版 (Micro-interactions & Typography)
- **Hover (懸停)**：以背景顏色深淺變化為主（例如按鈕從 `#ffffff` 變為 `#f1f5f9`），取代明顯的立體位移。
- **Active (點擊)**：細微的背景加深與輕微的 `scale-[0.98]` 點擊回饋。
- **表頭強制小字**：表格表頭 (th) 必須設定 `11px font-bold text-[var(--text-muted)] uppercase tracking-wider`。

## 組件藍圖：表格 (Table Blueprint)
請嚴格使用以下結構產出表格：
```html
<div class="overflow-hidden rounded-lg border-[0.5px] border-[var(--border-hairline)] bg-[var(--bg-surface)]">
    <table class="w-full text-left border-collapse">
        <thead>
            <tr class="bg-[var(--bg-panel)] border-b-[0.5px] border-[var(--border-hairline)]">
                <th class="py-2.5 px-4 text-[11px] font-bold text-[var(--text-muted)] uppercase tracking-wider">欄位標題</th>
            </tr>
        </thead>
        <tbody>
            <tr class="border-b-[0.5px] border-[var(--border-hairline)] hover:bg-[#fafaf9]">
                <td class="py-3 px-4 text-[13px] text-[var(--text-primary)]">內容</td>
            </tr>
        </tbody>
    </table>
</div>
```
