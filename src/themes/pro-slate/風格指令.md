# 💼 專業冷灰 (Pro Slate / Cool Slate Modern Studio) 風格指令

## 1. 風格定位與設計哲學
- **核心定位**：現代 SaaS 工作室、精密工業級設計、極簡 Slate 灰階架構。
- **設計哲學**：全面消除手繪粗線與不規則陰影，採用幾何精確的 1px 細微邊框、8px 精準圓角、霧面冷灰底色 (`#e2e8f0`)、深石墨導覽列 (`#1e293b`) 與純白操作卡片 (`#ffffff`)，營造媲美 Linear、Figma 等頂級設計工具的專業生產力體驗。

## 3. 幾何精密化與去手繪規範

### 3.1 手繪風格覆寫 (Anti-Sketch Rules)
- **取消雙層硬黑邊**：邊框一律強制設為 `border: 1px solid #cbd5e1`。
- **取消立體硬陰影**：改為平滑柔和的自然擴散陰影 `box-shadow: 0 2px 5px rgba(15, 23, 42, 0.06)`。
- **圓角標準化**：所有容器、按鈕與卡片統一收斂至 `border-radius: 8px`。

### 3.2 字體 (Typography)
- **字型族**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- **字重規範**：一般文字 `400 (Regular)`、操作標籤 `600 (Semi-Bold)`、重要標題 `700 ~ 800 (Bold)`。

## 4. 各功能區塊風格指令

### 4.1 頂部導覽列 (Header)
- 背景採用 `#1e293b`（深石墨），底邊框為 `1px solid #334155`。
- 回儀表板按鈕採用純白底搭配俐落冷灰微框。
- 專案標題直接以純白大字呈現，編輯框使用俐落冷灰白底。

### 4.2 專案儀表板 (Dashboard)
- 背景使用漸層 `radial-gradient(circle at 50% 0%, #f1f5f9 0%, #e2e8f0 100%)`。
- 專案卡片使用純白卡片底，搭配 1px `#cbd5e1` 邊框與柔和陰影。
- Hover 卡片向上浮動 1.5px，產生 `0 8px 20px rgba(15, 23, 42, 0.1)` 陰影。

### 4.3 畫布工作區 (Canvas & Workspace)
- 畫布視圖外部使用 `#e2e8f0` 霧面襯底，突出純白畫布本身。
- 工具箱、圖層列與屬性面板全採用純白純淨卡片風。
- 浮動工具列（Floating Toolbar）使用純白毛玻璃底搭配細微冷灰線。

### 4.4 登入與身分認證 (Auth Modal)
- 登入彈窗採用純白精緻卡片，搭配 1px 冷灰外框與深石墨漸層 Header。
- 登入按鈕採用俐落 Sky Blue (`#0284c7`)，無手繪黑框。

---

## 5. CSS 擴充與選擇器準則
- 所有專業冷灰專屬樣式必須掛載在 `[data-theme="pro-slate"]` 或 `body.theme-pro-slate` 作用域下。
- 使用 `!important` 確保完整覆蓋原本的手繪 `sketch-*` 類別與 Tailwind 樣式。
