# 💼 專業冷灰 (Pro Slate / Cool Slate Modern Studio) 風格指令 V2

> **⚠️ 遵循聲明**
> 開發此主題時，必須同時遵守 [全系統風格指令總綱 V2](../風格指令v2.md) 中的所有禁止事項與互動規範。本文件專注於定義 Pro Slate 主題的嚴謹 Design Tokens 與專屬 Component Blueprints。

## 1. 風格定位與設計哲學 (V2 升級版)
- **核心定位**：極致扁平、高密度的 SaaS 生產力工具介面。
- **設計哲學升級**：在原版冷灰色系的基礎上，**全面拔除所有卡片與按鈕的「柔和懸浮陰影」**。將設計從「視覺擬物化」徹底轉向「資訊層級化」，僅依靠 `0.5px` 的細微實心灰框來切割區塊。

---

## 2. 決定性色彩調色盤 (Strict Design Tokens)

**絕對禁止**在此主題內使用非以下定義之顏色或 Tailwind 預設色：

| CSS 變數 (Token) | Hex 色碼 | 嚴格使用場景 |
| :--- | :--- | :--- |
| `--bg-app` | `#e2e8f0` | 全域應用程式最底層冷灰襯底 |
| `--bg-panel` | `#f1f5f9` | 側邊欄、工具箱、次要容器底色 |
| `--bg-surface` | `#ffffff` | 主要內容區、表單、卡片之純淨底色 |
| `--border-hairline` | `rgba(15, 23, 42, 0.1)` | **0.5px 專用！** (或極淡色 1px `#cbd5e1`) 用於所有區塊分隔 |
| `--accent-primary` | `#0f172a` | **主按鈕專用**（黑底白字），確保與狀態色分離 |
| `--status-success` | `#059669` | **僅限**成功、發布、完成狀態 |
| `--status-danger` | `#dc2626` | **僅限**刪除、錯誤提示 |
| `--text-primary` | `#0f172a` | 標題、重要內文（深炭黑） |
| `--text-muted` | `#64748b` | 輔助說明、非焦點文字 |

## 3. 視覺限制指令 (Visual Constraints)

### 3.1 陰影與邊框 (Strict Border & Shadow Rules)
- **零陰影原則**：所有卡片 (`.theme-card`)、一般按鈕 (`.theme-btn`) **絕對不可**有 `box-shadow`。
- **浮層專屬陰影**：僅有右側滑出的 Drawer 或置中 Modal 允許使用 `box-shadow: -10px 0 44px rgba(0,0,0,0.1)` (抽屜) 或 `0 20px 60px rgba(0,0,0,0.15)` (彈窗)。

### 3.2 字體與排版 (Typography)
- **禁止全大寫氾濫**：除非是 Table Header (表頭) 或極小的 Tag，一般文字禁止使用 `uppercase`。
- **表頭強制小字**：表頭 (th) 必須設定 `11px font-bold text-[var(--text-muted)] tracking-wider`。

---

## 4. 元件標準骨架 (Component Blueprints)

### 4.1 表格骨架 (Table Blueprint)
請嚴格使用以下結構產出表格，不可隨意更改 Tailwind 排列方式：
```html
<div class="overflow-hidden rounded-lg border-[0.5px] border-[var(--border-hairline)] bg-[var(--bg-surface)]">
    <table class="w-full text-left border-collapse">
        <thead>
            <tr class="bg-[var(--bg-panel)] border-b-[0.5px] border-[var(--border-hairline)]">
                <th class="py-2.5 px-4 text-[11px] font-bold text-[var(--text-muted)] uppercase tracking-wider">欄位標題</th>
            </tr>
        </thead>
        <tbody>
            <!-- hover 狀態必須極淡 -->
            <tr class="border-b-[0.5px] border-[var(--border-hairline)] hover:bg-[#fafaf9]">
                <td class="py-3 px-4 text-[13px] text-[var(--text-primary)]">內容</td>
            </tr>
        </tbody>
    </table>
</div>
```

## 5. CSS 擴充與選擇器準則
- 所有樣式宣告必須包裹在 `[data-theme="pro-slate"]` 選擇器之下。
- 使用 `!important` 確保強制覆蓋原有厚重的預設 Tailwind 陰影。
