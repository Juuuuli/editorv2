# 可直接貼給 AI 的提示詞 (Auth Modal)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要產出一個符合系統身分認證與登入彈窗 (Auth Modal) 的元件。這是一個支援 4 大主題無縫切換的彈窗，請嚴格遵守以下規範。

## 元件定位與無障礙設計 (A11Y)
- **浮層特例**：這是一個 Modal 彈窗，因此是**少數被允許使用 `box-shadow` 的元件**，以創造與底層背景分離的「浮層感」。
- **無障礙屬性**：最外層遮罩必須包含 `role="dialog"`, `aria-modal="true"`, 以及 `aria-labelledby`，這是絕對要求。

## 組件藍圖 (Modal Blueprint)
請嚴格使用以下結構產出彈窗，切換 `data-auth-theme` 將自動對應四種 V3 主題的色票映射：
```html
<div class="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/40 backdrop-blur-sm" role="dialog" aria-modal="true" aria-labelledby="auth-modal-title">
    <div class="theme-modal-container w-full max-w-[480px] rounded-xl overflow-hidden shadow-[0_20px_60px_rgba(0,0,0,0.3)] transition-colors duration-300 relative" data-auth-theme="pro-slate">
        <!-- Header -->
        <div class="theme-modal-header p-6 pb-4 border-b-[0.5px] border-[var(--border-hairline)] flex justify-between items-center">
            <h2 id="auth-modal-title" class="text-[16px] font-bold text-[var(--text-primary)]">登入系統</h2>
        </div>
        <!-- Body (表單) -->
        <div class="theme-modal-body p-6 space-y-4">
            <!-- Form Inputs ... -->
        </div>
        <!-- Footer (動作) -->
        <div class="theme-modal-footer p-6 pt-0 flex justify-end">
            <button class="px-6 py-2 rounded-lg font-bold text-[13px] bg-[var(--accent-primary)] text-[var(--bg-surface)]">
                登入
            </button>
        </div>
    </div>
</div>
```

## 防呆與狀態管理
- **註冊通道鎖定**：若註冊功能關閉，**禁止**只是將按鈕變灰。必須使用 Note 元件在表單上方顯示具體原因（如：「因系統升級，註冊通道暫停開放至月底」）。
- **表單禁用狀態**：被禁用的輸入框除了透明度降低 (`opacity: 0.6`) 外，邊框應轉為點狀或虛線，嚴格區分可編輯狀態。
