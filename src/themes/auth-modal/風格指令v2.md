# 🎭 身分認證與登入彈窗 (Auth Modal Multi-Theme) 風格指令 V2

> **⚠️ 遵循聲明**
> 此為共用元件指令。必須同時遵守 [全系統風格指令總綱 V2](../風格指令v2.md) 中的所有禁止事項。本文件專注於定義 Modal 等級浮層的嚴謹結構與無障礙 (A11Y) 規範。

## 1. 模組定位與設計哲學 (V2 升級版)
- **核心定位**：訪客進入系統的第一印象與身分把關者。
- **UX 互動升級**：作為一個 Modal (彈窗)，它是**少數被允許使用 `box-shadow` 的元件**，以創造與底層背景分離的「浮層感」。
- **主題沙盒 (Theme Sandbox)**：繼續支援 4 大主題無縫連動切換，但切換的按鈕必須遵守「禁止過度裝飾」原則。

---

## 2. 元件標準骨架 (Modal Blueprint)

**絕對禁止**隨意用 `div` 拼湊彈窗。登入彈窗**必須**包含以下無障礙屬性 (`role="dialog"`, `aria-modal="true"`)，以及固定的遮罩結構：

```html
<!-- [Blueprint] Standard Modal Structure -->
<div class="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/40 backdrop-blur-sm" 
     role="dialog" 
     aria-modal="true" 
     aria-labelledby="auth-modal-title">
     
    <!-- Modal 容器 (在此處切換 data-auth-theme) -->
    <div class="theme-modal-container w-full max-w-[480px] rounded-xl overflow-hidden shadow-[0_20px_60px_rgba(0,0,0,0.3)] transition-colors duration-300 relative"
         data-auth-theme="pro-slate">
         
        <!-- Header 區 -->
        <div class="theme-modal-header p-6 pb-4 border-b-[0.5px] border-[var(--border-hairline)] flex justify-between items-center">
            <h2 id="auth-modal-title" class="text-[16px] font-bold text-[var(--text-primary)]">登入系統</h2>
            <!-- Style Switcher 列放在 Header 的右側或緊接下方 -->
        </div>
        
        <!-- Body 區 (表單) -->
        <div class="theme-modal-body p-6 space-y-4">
            <!-- Form Inputs ... -->
        </div>
        
        <!-- Footer 區 (動作) -->
        <div class="theme-modal-footer p-6 pt-0 flex justify-end">
            <!-- 唯一的主按鈕 -->
            <button class="px-6 py-2 rounded-lg font-bold text-[13px] bg-[var(--accent-primary)] text-white">
                登入
            </button>
        </div>
    </div>
</div>
```

---

## 3. 防呆與鎖定規範 (Anti-Errors)

- **註冊通道鎖定**：若註冊功能關閉，**禁止**只是將按鈕變灰。必須使用 Note 元件在表單上方顯示原因（如：「因系統升級，註冊通道暫停開放至月底」）。
- **表單禁用狀態**：被禁用的輸入框除了 `opacity: 0.6`，邊框應轉為點狀或虛線，嚴格區分可編輯狀態。

---

## 4. 4 大主題在彈窗上的具體映射限制

在 `data-auth-theme` 切換時，Agent 必須更新 `.theme-modal-container` 的 CSS 變數：
- **`light` (經典手繪)**：保留不規則手繪按鈕，但移除不必要的底色陰影。
- **`dark` (深色極客)**：將 Modal 外陰影改為電光藍光暈 `0 20px 60px rgba(99,102,241,0.2)`。
- **`pro-slate` (專業冷灰)**：極度純淨的白底，`0.5px` 冷灰外框。
- **`retro-warm` (復古文青)**：羊皮紙底，深胡桃木 Header。
