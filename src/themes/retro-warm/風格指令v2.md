# 📜 復古文青 (Retro Warm / Vintage Kraft Journal) 風格指令 V2

> **⚠️ 遵循聲明**
> 開發此主題時，必須同時遵守 [全系統風格指令總綱 V2](../風格指令v2.md) 中的所有禁止事項與互動規範。本文件專注於定義 Retro Warm 主題的嚴謹 Design Tokens 與專屬 Component Blueprints。

## 1. 風格定位與設計哲學 (V2 升級版)
- **核心定位**：帶有復古手帳溫度、適合長文閱讀的出版物質感後台。
- **設計哲學升級**：原版設計在所有卡片都加上了「手帳壓印陰影」，這在大量資料列出時會顯得繁雜。V2 版將**壓印陰影嚴格限制在「主要操作按鈕 (封蠟鈕)」**，其餘卡片與表格區塊全面回歸 `0.5px` 的皮革棕邊框平鋪排列。

---

## 2. 決定性色彩調色盤 (Strict Design Tokens)

**絕對禁止**在此主題內使用純灰 (`#f5f5f5`, `#gray-500`) 等無機色。所有背景與邊界必須帶有暖色調 (Warm tone)：

| CSS 變數 (Token) | Hex 色碼 | 嚴格使用場景 |
| :--- | :--- | :--- |
| `--bg-app` | `#f5eedc` | 最底層牛皮紙溫潤色 |
| `--bg-panel` | `#fdfaf5` | 卡片、編輯區的紙白底色 |
| `--bg-header` | `#36261c` | 頂部導覽列（深胡桃木色） |
| `--border-hairline`| `rgba(133, 99, 75, 0.25)` | **0.5px 專用！** 用於表格、卡片分割線 |
| `--border-strong` | `#85634b` | 僅用於強調區塊的 1px 皮革棕邊框 |
| `--accent-primary` | `#b45309` | **主按鈕專用**（焦糖琥珀封蠟），搭配白字 |
| `--status-success` | `#4d7c0f` | **僅限**成功、狀態正常 (鼠尾草綠) |
| `--status-danger` | `#991b1b` | **僅限**警告、刪除 (暗封蠟紅) |
| `--text-primary` | `#38271d` | 主文字墨棕色（取代刺眼純黑） |
| `--text-muted` | `#785b46` | 次要文字暖灰棕 |

## 3. 視覺限制指令 (Visual Constraints)

### 3.1 陰影與質感的收斂 (Focused Textures)
- **零陰影卡片**：所有 `.theme-card` 必須拔除原有陰影。
- **封蠟鈕特例**：代表「建立」、「儲存」的 `--accent-primary` 按鈕，允許保留 `box-shadow: 2px 2px 0px rgba(133, 99, 75, 0.25)` 營造火漆印章質感。
- **字體強制**：系統預設字體全面掛載為 `serif` (`Noto Serif TC`, `Georgia`)。除數值外，避免使用無襯線字體。

### 3.2 Note 提示框 (防呆對話框)
若需提示使用者系統限制，提示框應表現如「編輯便籤」：
- 左側邊條改為 `--status-amber` (`#b45309`)。
- 背景為極淡的焦糖色，與 `--bg-panel` 產生輕微對比。

---

## 4. 元件標準骨架 (Component Blueprints)

### 4.1 狀態標籤骨架 (Tag Blueprint)
狀態標籤在此主題下不使用過度現代的「藥丸(Pill)」全圓角，而是呈現書籍索引標籤的微圓角 (4px)：
```html
<!-- [Blueprint] Retro Tag (Success) -->
<span class="inline-flex items-center px-2 py-0.5 rounded-[4px] border border-[var(--status-success)] bg-[#f3f6ee] text-[var(--status-success)] text-[11px] font-bold">
    <i class="fas fa-check-circle mr-1"></i> 已發布
</span>
```
