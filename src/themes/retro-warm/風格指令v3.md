# 可直接貼給 AI 的提示詞 (Retro Warm)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要用以下設計風格產出介面。這是一套**充滿溫潤手帳溫度、復古羊皮紙質感、適合長文閱讀的出版物質感後台**，請嚴格遵守。

## 色彩 (Design Tokens)
絕對禁止使用純灰（如 `#f5f5f5`）等無機色或純黑/白，請遵守以下帶暖色調的設定：
- 全域畫布背景 (`--bg-app`)：`#f5eedc` 或 `#ede2cd`（牛皮紙暖色）
- 卡片/側邊欄/編輯區 (`--bg-panel`)：`#fdfbf7` 或 `#fdfaf5`（羊皮紙白）
- 頂部 Header (`--bg-header`)：`#36261c`（深胡桃木色）
- 細邊框 (`--border-hairline`)：`rgba(133, 99, 75, 0.25)`（0.5px 專用，用於表格、卡片分割）
- 強調邊框 (`--border-strong`)：`#85634b` 或 `#5c412f`（1.5px 或 1px 皮革棕邊框）
- 主按鈕 (`--accent-primary`)：`#b45309`（焦糖琥珀封蠟），搭配白字
- 主文字 (`--text-primary`)：`#38271d`（主文字墨棕色，取代純黑）
- 輔助文字 (`--text-muted`)：`#785b46`（暖灰棕）
- 狀態色：成功 `#4d7c0f` (鼠尾草綠)、危險 `#991b1b` (暗封蠟紅)

## 三個不可妥協的特徵
1. **陰影與質感的收斂**：所有一般卡片 (`.theme-card`) 必須拔除陰影，回歸平鋪。壓印陰影嚴格限制在「主要操作按鈕 (封蠟鈕)」（如儲存按鈕允許 `box-shadow: 2px 2px 0px rgba(133, 99, 75, 0.25)`）與需要陽光灑落立體感的少數浮層。
2. **溫潤的線條與字體強制**：系統字體全面掛載為襯線字體 (`serif`, 包含 `Noto Serif TC`, `Georgia`)。除數值外，避免使用無襯線字體。邊框使用 `0.5px` 分割或 `1.5px` 強調框。
3. **防呆對話框 (Note) 的便籤感**：提示框應表現如「編輯便籤」，左側邊條改為 `--accent-primary` (`#b45309`)，背景為極淡焦糖色，與羊皮紙底產生輕微對比。

## 組件藍圖：狀態標籤 (Retro Tag)
狀態標籤不使用過度現代的「藥丸(Pill)」全圓角，而是呈現書籍索引標籤的微圓角 (4px)：
```html
<span class="inline-flex items-center px-2 py-0.5 rounded-[4px] border border-[var(--status-success)] bg-[#f3f6ee] text-[var(--status-success)] text-[11px] font-bold">
    <i class="fas fa-check-circle mr-1"></i> 已發布
</span>
```
