# 可直接貼給 AI 的提示詞 (Retro Warm)

把下面 `---` 之間的內容整段複製，貼給任何 AI（Claude、ChatGPT、Cursor…），
接著描述你要做的畫面即可。技術中立，HTML/React/Vue/Tailwind 都適用。

---

你要用以下設計風格產出後台管理介面。這是一套**充滿溫潤手帳溫度、復古羊皮紙質感、適合長文閱讀的出版物質感後台**風格，請嚴格遵守。

## 色彩

中性色（復古暖色，絕對禁止純灰與純黑白）：
- 頁面底 `--bg-app` `#f5eedc` 或 `#ede2cd`（牛皮紙暖色）
- 側欄或卡片底 `--bg-panel` / `--bg-surface` `#fdfbf7` 或 `#fdfaf5`（羊皮紙白）
- 頂部 Header `--bg-header`：`#36261c`（深胡桃木色）
- 細邊框 `--border-hairline`：`rgba(133, 99, 75, 0.25)`（0.5px 專用，用於分割）
- 強調邊框 `--border-strong`：`#85634b` 或 `#5c412f`（1.5px 或 1px 皮革棕邊框）
- 主文字 `--text-primary` `#38271d`（墨棕色，取代純黑）／輔助文字 `--text-muted` `#785b46`（暖灰棕）

語意色（沉穩大地與植物色系）：
- 主按鈕 `--accent-primary`：`#b45309`（焦糖琥珀封蠟，搭配白字）
- 成功 green：`#4d7c0f`（鼠尾草綠）
- 危險 red：`#991b1b`（暗封蠟紅）

規則：絕對禁止使用純無機色（如 `#f5f5f5`, `#000000`）。所有狀態與提示色必須帶有復古、低飽和的大地色質感。

## 三個不可妥協的特徵

1. **陰影與質感的收斂**：所有一般卡片 (`.theme-card`) 必須拔除陰影，回歸平鋪。壓印陰影嚴格限制在「主要操作按鈕 (封蠟鈕)」（如 `box-shadow: 2px 2px 0px rgba(133, 99, 75, 0.25)`）與需要陽光灑落立體感的少數浮層。
2. **溫潤的線條與字體強制**：系統字體全面掛載為襯線字體 (`serif`)。除數值外避免使用無襯線。邊框使用 `0.5px` 半透明或 `1.5px` 強調框。
3. **防呆對話框 (Note) 的便籤感**：提示框應表現如「編輯便籤」，左側邊條改為 `--accent-primary` (`#b45309`)，背景為極淡焦糖色，與羊皮紙底產生輕微對比。

## 字型與尺度

字型：全面使用襯線字體 `Noto Serif TC, Georgia, serif`（除純數值外）。基準 14px / 1.5。
圓角：不使用過度現代的全圓角，狀態標籤使用書籍索引標籤微圓角 `4px`，卡片 `8px`。
陰影：平面設計，只有主要動作按鈕有 `2px 2px 0px` 的實體壓印陰影，卡片表格一律無陰影。

## 版面

頂欄 56px（深胡桃木色 #36261c）。內容區置中或展開，卡片堆疊在牛皮紙背景上。

## 元件

- **按鈕**：主要動作按鈕為封蠟質感（焦糖琥珀色，帶實體壓印陰影）；次要按鈕為透明羊皮底加皮革棕邊框。
- **卡片**：無陰影平鋪，僅帶 `0.5px` 細邊框，標題呈現印刷出版物質感。
- **表格**：外層負責 0.5px 邊框。表頭次要底色；最後一列不畫底線。
- **狀態標籤**：復古索引標籤 `4px` 微圓角，用語意色的極淺底色＋文字色。
- **提示框**：左側 3px 實心焦糖色邊條＋淺淡焦糖底色，呈現便籤感。
- **彈窗／抽屜**：彈窗打斷、抽屜輔助（右側滑入）。

## 互動慣例（務必遵守，這比視覺更能決定成品像不像）

1. **層級式操作**：不要一頁攤開所有資料與設定。第一層只給列表，點選某列後從**右側抽屜**展開該筆的詳細設定。
2. **用提示框解釋取捨**：寫「為什麼這樣設計、不這樣會怎樣」，格式為「**取捨標題：**做法 —— 因為 A，若改成 B 會導致 C」。
3. **長說明收進按鈕後面**：長篇說明文件不攤在頁面上，點按鈕後滑出抽屜。
4. **破壞性操作要防呆**：擋住會讓系統無法挽回的狀態，並說明原因。

## 文案風格

優雅、復古的手帳編輯者語氣，像一位願意解釋的主編。講因果不只講規則。錯誤訊息要具體。

## 無障礙

彈窗與抽屜要 `role="dialog"`、`aria-modal="true"`；純圖示按鈕要 `aria-label`；動畫尊重 `prefers-reduced-motion`。
