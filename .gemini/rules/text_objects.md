# 文字物件實作規則 (Text Objects Rules)

## 1. 文字與圖片的等價性
- **功能一致性**：使用者「新增的文字」以及透過 AI「智慧辨識 (OCR)」產生出來的文字，在畫布上的操作層級必須與「圖片」完全相同。這意味著文字物件必須能夠被任意選取、平移、群組化 (Group)、甚至進行層級調整。

## 2. 邊框與縮放限制
- **字體大小固定原則**：當使用者拉扯文字的邊框（變寬或拉長）時，**文字必須維持原本的字體大小 (FontSize)**，不應該隨著拖曳而整體被拉伸變形。
- **組件選擇**：為了達成上述需求，必須一律使用 `fabric.Textbox` 而非原生的 `fabric.Text` 或 `fabric.IText`。
- **控制點限制**：必須隱藏上下垂直控制點 (`setControlsVisibility({ mt: false, mb: false })`)，避免使用者垂直拉伸導致文字內容被強制擠壓變形。
- **自動換行**：必須設定 `splitByGrapheme: true` 來支援中文字元的正常斷行與排版。
