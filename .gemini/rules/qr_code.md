# QR Code 實作與樣式規則 (QR Code Rules)

## 1. 生成流程與 UI 互動
- **網址輸入強制化**：點擊 QR 條碼功能時，必須強制跳出對話框 (Modal)，等待使用者輸入網址或文字後，按下確認才能生成物件，禁止未經輸入就產生預設的條碼。

## 2. 樣式支援與底層庫選擇
- **進階樣式支援**：為了支援使用者自訂「外觀樣式」(例如：圓點、方塊) 以及「眼框樣式」(Corners)，必須放棄基礎的 `qrcodejs` 函式庫，全面採用 `qr-code-styling` 作為底層生成引擎。
- 產生的 QR Code 必須支援顏色調整與外觀切換，並且以屬性面板 (Properties Panel) 為統一修改入口。

## 3. 物件無縫替換
- 由於使用了外部函式庫生成進階的 QR Code 圖片，當使用者在面板修改樣式 (如：顏色、圓角) 時，系統會產生一張全新的 DataURL 圖片。
- **替換規則**：在做屬性更新時，必須讀取舊有 QR Code 的所在位置 (left, top) 與縮放比例 (scaleX, scaleY)，將新的圖片物件放置於該座標，並移除舊圖，達成視覺上的「無縫刷新」與即時預覽效果。
