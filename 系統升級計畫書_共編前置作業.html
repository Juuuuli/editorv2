多人共編前置作業計畫書

本計畫旨在徹底解決「所有專案共享單一 URL」之痛點，為每個專案賦予唯一的深層網址 (Deep Link)，並在右上角使用者中心整合「專案協作與分享」入口與零伺服器廣播前置通訊層，為後續正式導入 Yjs CRDT 與多人即時同步鋪平道路。

01

升級背景與現狀痛點分析

現行架構痛點 (`v1.4.1`)
  • 單一 URL 混淆：無論在儀表板或開啟任何專案，瀏覽器網址固定為 https://.../editorv2/，無法直通特定專案。
  • 無法加入書籤或傳遞：使用者無法把工作中的專案加入瀏覽器書籤或直接將網址丟給同仁。
  • 瀏覽器歷史失效：按瀏覽器「上一頁/下一頁」無法在專案與儀表板間自然切換。
  • 缺乏共編入口與身分識別：尚未具備生成邀請連結、房號與協作者身分標識機制。
前置作業升級目標 (`v1.4.2`)
  • SPA 專案路由 (History API)：實現 ?project=proj_xxx 網址規格，完美相容 GitHub Pages。
  • 原生支援 Deep Linking & Popstate：網址貼上即開專案，按返回鍵流暢退回儀表板。
  • 右上角「專案協作與分享」彈窗：收納於使用者下拉選單，提供一鍵複製共編網址與房間碼。
  • 協作者 Presence 標識與單機測試通道：提供隨機個人色彩與 BroadcastChannel 雙分頁測試能力。
02

四大前置升級核心 (Feature Specifications)

Core 1 · Routing

1. 前端專案路由引擎 (ProjectRouter)

基於 window.history.pushState 與 URLSearchParams，在靜態託管環境下提供全功能 SPA 路由。

// 網址規格 (URL Patterns)
首頁儀表板: /editorv2/
編輯專案: /editorv2/?project=proj_172290183
加入共編: /editorv2/?project=proj_172290183&room=893214
  • 開機自動解析 URL 參數，若帶有 project 則自動跳過首頁直通該專案。
  • 監聽 window.onpopstate，點擊瀏覽器返回鍵無縫返回儀表板。
Core 2 · Share UI

2. 右上角「分享與協作」選單與彈窗

收納於右上角使用者下拉選單（AuthManager / UserMenu），點擊開啟手繪風格「專案協作與分享中心」Modal。

一鍵複製專案共編網址 含 room 與 project 參數
6 位數房間邀請碼 892-140
權限切換 可編輯 (Editor) / 僅檢視 (Viewer)
Core 3 · Presence

3. 協作者 Presence 身分與專屬配色

從 AuthManager 自動提取當前登入者名稱（如公用管理員或訪客），並指派專屬識別色。

  • 自動隨機分配協作者專屬色（Pink, Cyan, Violet, Amber, Emerald）。
  • 產生協作者 Token 結構：{ userId, name, color, role, joinedAt }。
  • 在頂部導覽列預留在線成員頭像堆疊容器 (Avatar Stack)。
Core 4 · Local Collab

4. 單機雙分頁測試通道 (BroadcastChannel)

利用原生 BroadcastChannel API，在開發階段無需架設後端 Server 即可實現跨分頁即時測試。

new BroadcastChannel(`editor_room_${roomId}`)
同台電腦開啟一般分頁 + 無痕分頁，一邊拖曳文字/圖形，另一邊即時同步並顯示對方游標！

模組架構與檔案目錄規劃

嚴格遵守 SDLC 模組化隔離原則，所有共編前置邏輯收納於 src/features/collaboration/ 專屬目錄，路由收納於 src/core/：

├── features/

│ │ ├── PresenceManager.js # [NEW] 協作者色彩與身分狀態
│ │ ├── CollabChannel.js # [NEW] 本機廣播通道 (BroadcastChannel)
│ │ └── index.js # [NEW] 模組統一出口
│ ├── auth/
│ │ └── AuthManager.js # 整合使用者選單協作入口
│ └── dashboard/

└── docs/
├── 系統升級計畫書_共編前置作業.html
└── 功能規格_專案路由與協作前置.md
EventBus 全域事件註冊
• ROUTER:PROJECT_CHANGED: 網址專案切換事件
• ROUTER:NAVIGATE_DASHBOARD: 返回儀表板事件
• COLLAB:OPEN_SHARE_MODAL: 開啟分享協作彈窗
• COLLAB:ROOM_JOINED: 成功加入房間廣播通道
• COLLAB:PRESENCE_UPDATE: 在線協作者名冊變更
UI 風格規範相容

分享彈窗完全遵循 .sketch 手繪雙線邊框、shadow-[3px_3px_0px_#334155] 與四套主題變數（Light Sketch / Dark / Pro / Retro）動態適配。

05

驗收標準與開發規範 (Acceptance Criteria)

功能驗收標準

  • 網址專屬性：進入任一專案，瀏覽器網址即時變為 ?project=[ID]。
  • Deep Link 直通：複製網址在另一個分頁打開，能正確直接載入該專案。
  • 瀏覽器上一頁：在編輯器中點擊瀏覽器返回鍵，順暢退回專案儀表板。
  • 分享彈窗功能：點擊使用者選單「分享與協作」，能順利複製帶有房間參數之 URL，並提示成功複製。
  • 單機跨分頁測試：開啟兩個分頁進入同專案，能偵測到對方在線。

程式碼品質與規範要求

  • 零跨模組污染：不可在 CanvasEngine 內直接寫死分享 DOM，必須透過 EventBus 與獨立模組解耦。
  • 相容現有主題：分享彈窗必須完整支援手繪、深色、冷灰與復古主題。
  • 代碼註解與規格齊全：包含完整 JSDoc 與繁體中文說明文件。
  • 版號自動推進：完成後全域升級至 v1.4.2 並同步 GitHub。
