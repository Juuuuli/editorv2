  - 登入帳號角色優先於 URL `?role=viewer` 限制。
- **主端 vs 客端 判斷機制**（⚠️ 較脆弱）：
  - `project.isShared === true` 代表客端（由 `COLLAB:SNAPSHOT_RECEIVED` 中設定）。
  - 主端自建專案不含 `isShared`，視為擁有者 (admin)。
- **Tailwind v4 Bug 注意事項**：本專案使用 Tailwind v4 (`@tailwindcss/postcss`)，在動態綁定含有 `z-[60]` 等字串於 JS 的 className 時，掃描器無法正確識別。必須將這類重要的自訂工具寫在 `style.css` (非 `@layer utilities` 內) 或確保使用白名單機制。
- **Canvas Tainted 注意事項**：若遇到從外部（如 Firebase）無 CORS 載入圖片到 Canvas，會導致 Canvas 成為 tainted 狀態，無法執行 `toDataURL`。若執行會拋出 SecurityError，必須善用 `try...catch...finally` 攔截以避免終止整個程式流程（尤其影響 `setViewportTransform` 等視角還原機制）。
- **最新 Git Commit (main 分支)**: `74c80b8` fix(thumbnails): preserve local thumbnails during Yjs sync and add fallback for tainted canvas
