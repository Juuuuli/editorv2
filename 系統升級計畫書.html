02 升級核心架構 · 深度技術設計

各模組切分、架構設計與實現方案評估

FEATURE 04 · 已完成 ✅

4. 檔案管理與專案儀表板 (Project Dashboard)

v1.2.0 · Sprint 1 (已交付)

打造類似 Canva / Figma 的主頁儀表板。提供專案卡片網格、即時預覽縮圖、專案建立、複製、重命名、刪除與本機自動儲存機制。

持久化儲存技術

使用瀏覽器底層 IndexedDB (封裝成 ProjectStorageEngine)，無上限儲存專案 JSON、多頁快照與縮圖。

首頁儀表板功能
  • • 新增空白專案 (可選 16:9 / 4:3 / A4)
  • • 複製現有專案副本 (Duplicate)
  • • 專案重命名、建立標籤分類
  • • 匯入 / 匯出 .editorproj 專案包
自動存檔機制 (Auto-Save)

防抖 (Debounce 800ms) 背景自動更新 IndexedDB，徹底避免瀏覽器誤關導致資料遺失。

FEATURE 02 · 已完成 ✅

2. 顏色模板與多風格主題切換 (Multi-Theme System)

v1.3.0 · Sprint 2 (已交付)

建構全域設計代幣 (Design Tokens) 系統，支援即時無縫切換深色、淺色手繪、復古文青、專業冷灰 (Pro Slate) 等多種主題風格。

🌙 深色極客風 (Dark)

深灰黑底 (#0f172a) 搭配發光微霓虹按鈕，適合夜間與長時間專注創作。

🎨 經典手繪風 (Light Sketch)

目前預設風格。鵝黃暖白底配合雙線手繪邊框，童趣且親和力高。

💼 專業專業風 (Pro Slate)

Figma / Photoshop 經典冷灰配置，去除非必要裝飾，極致簡約。

📜 復古文青風 (Pastel/Retro)

莫蘭迪粉彩與米白格紋網格，提升設計質感與視覺趣味。

FEATURE 05 · 已完成 ✅

5. 角色帳號、登入/註冊介面與公用權限控管 (Role & Account Guard)

v1.4.0 · Sprint 3 (已交付)

提供完整的「登入 / 註冊」手繪風彈窗介面與狀態管理，配發「公用最高管理者帳密」並預留標準 RBAC 擴充性與「系統金鑰保險箱 (API Vault)」。

登入 / 註冊介面

右上角提供登入入口，支援帳密驗證、記住登入狀態 (Session/Token) 以及手繪風切換彈窗。

公用管理者帳密

配置公用主帳密，供團隊所有人登入以獲得系統完整操作與管理權限。

系統金鑰保險箱 (API Vault)

提供集中加密金鑰保管，管理 Clipdrop、Spark 或其他 AI 權杖。

FEATURE 06 · 即將進行 🚀

6. 專案網址路由化與共編前置作業 (Project Routing & Collab Prep)

預定版本：v1.5.0 · Sprint 4 (目前目標)

為每個專案建立唯一的 URL 路由 (Deep Linking)，並在右上角使用者選單中新增「專案協作與分享」彈窗、Presence 身分標識與單機 BroadcastChannel 測試通道。

SPA 前端專案路由

使用 ProjectRouter.js 實現 ?project=[ID] 專案網址與瀏覽器返回鍵 (Popstate) 支援。

分享與協作彈窗 (ShareModal)

收納於右上角使用者選單，一鍵複製共編連結、6 位數房間邀請碼與權限設定。

Presence & 本機廣播

協作者隨機配色標識，並透過 BroadcastChannel 支援單機跨分頁即時測試。

FEATURE 03 · AI 擴充

3. 多模型整合閘道與 Spark 預備架構 (AI Model Gateway)

預定版本：v1.6.0 · Sprint 5

重構系統 AI 工具的底層通訊層，建立統一的 Adapter 適配器介面。一旦公司內部 Spark 環境架設完成，即可直接無縫接入。

統一 Model Adapter

將「影像去背/修補」與「文字生成/潤飾」標準化，上層 UI 工具不綁定特定 API，透過 Provider 注入呼叫。

Spark 專屬串接通道

預留 Spark WebSocket/REST API 規格介面，具備 Token 流式傳輸與 Prompt 範本微調能力。

多模型測試切換面板

在「系統設定」中提供模型切換開關（預設 Clipdrop / 本地 Mock / 企業 Spark），方便進行 A/B 測試。

FEATURE 01 · 旗艦技術

1. 即時多人協作共編引擎 (Real-time Collaboration)

預定版本：v2.0.0 · Sprint 6~7 (旗艦攻堅)

實現多位使用者透過同一個專案連結同時進行編輯。包含即時多人游標位置 (Multiplayer Cursors)、物件編輯鎖定 (Selection Lease) 以及 衝突消解算法 (CRDTs)。

同步通訊架構 (Yjs / WebSocket)

採用業界標準 Yjs (CRDT) 或輕量級 WebSocket Relay Server，以 Delta 增量方式即時廣播物件座標與圖層變更。

多人在線游標與頭像

在畫布上渲染不同顏色的協作者游標與名字標籤；右上角顯示當前專案在線成員清單。

防衝突鎖定 (Object Lease)

當 A 選取並拖曳某個物件時，B 畫面上該物件會顯示鎖定框，防止畫面互相覆蓋抽動。
