01 專案現狀檢視與開發規範遵循

深度審查現有需求書 (v0-v2)、標準規範與程式碼目錄結構

現行模組架構

目前採用 Vite + Vanilla JS + Fabric.js。具備雙工作區（圖片 vs PPT/PDF 多頁模式）、事件匯流排 (EventBus.js) 與狀態快取 (pageStates)。

📁 src/core/ -> CanvasEngine 核心
📁 src/features/ -> 功能隔離模組
📁 src/shared/ -> EventBus 通訊中樞

嚴格遵守規範

完全遵循 .geminirules 與 SDLC 指引：

  • 絕對功能隔離：新升級模組全數放入獨立 feature 目錄。
  • UX 規則：手繪風 (.sketch) 介面、紅色虛線選取框、視角平移帶動底板。
  • 自動化版號：Fix -> Patch+1，Feature -> Minor+1。

升級關鍵突破點

目前專案為「單機純前端靜態頁面」，專案狀態一旦重整即消失（僅暫存在 RAM）。

要實現「檔案管理」與「多人共編」，必須重構儲存層（引進 IndexedDB 本機資料庫）並架設輕量即時同步協議（WebSocket / WebRTC / CRDTs）。

02 五大升級項目 · 深度技術設計

針對會議決議的五大功能進行模組切分、架構設計與實現方案評估

FEATURE 04 · 基石核心

4. 檔案管理與專案儀表板 (Project Dashboard)

優先級：P0 (最優先建置)

打造類似 Canva / Figma 的主頁儀表板。提供專案卡片網格、即時預覽縮圖、專案建立、複製、重命名、刪除與本機/雲端自動儲存機制。

持久化儲存技術

使用瀏覽器底層 IndexedDB (封裝成 ProjectStorageEngine)，可無上限儲存上百個專案之 JSON、多頁快照與高解析縮圖，離線可用且隨開隨載。

首頁儀表板功能
  • • 新增空白專案 (可選 16:9 / 4:3 / A4)
  • • 複製現有專案副本 (Duplicate)
  • • 專案重命名、建立標籤分類
  • • 匯入 / 匯出 .editorproj 專案包
自動存檔機制 (Auto-Save)

編輯器每當畫布觸發 CANVAS:DIRTY 事件時，進行防抖 (Debounce 800ms) 背景自動更新 IndexedDB，徹底避免瀏覽器誤關導致資料遺失。

FEATURE 02 · 視覺體驗

2. 顏色模板與多風格主題切換 (Multi-Theme System)

優先級：P1 (前期必備)

建構全域設計代幣 (Design Tokens) 系統，支援即時無縫切換深色、淺色手繪、復古羊皮紙、專業深灰 (Pro Slate) 等多種主題風格，契合不同使用情境。

🌙 深色極客風 (Dark)

深灰黑底 (#0f172a) 搭配發光微霓虹按鈕，適合夜間與長時間專注創作。

🎨 經典手繪風 (Light Sketch)

目前預設風格。鵝黃暖白底配合雙線手繪邊框，童趣且親和力高。

💼 專業專業風 (Pro Slate)

Figma / Photoshop 經典冷灰配置，去除非必要裝飾，極致簡約。

📜 復古文青風 (Pastel/Retro)

莫蘭迪粉彩與米白格紋網格，提升設計質感與視覺趣味。

FEATURE 05 · 權限架構

5. 角色帳號、登入/註冊介面與公用權限控管 (Role & Account Guard)

優先級：P2 (中期建置)

提供完整的「登入 / 註冊」手繪風彈窗介面與狀態管理。現階段配發一組「公用最高管理者帳密」作為目前唯一能登入並控管/使用系統的憑證，同時於底層預留標準 RBAC (Role-Based Access Control) 擴充彈性，以利未來多帳號權限擴展。

登入 / 註冊介面

右上角提供登入入口，支援帳密驗證、記住登入狀態 (Session/Token) 以及手繪風登入/註冊切換彈窗。

公用管理者帳密

目前設定一組公用主帳密（可於設定檔配置），供團隊所有人登入以獲得系統完整操作與管理權限。

預留 RBAC 角色矩陣

預留 Admin (擁有者)、Editor (協作者) 與 Viewer (僅檢視) 權限檢查機制，未來開放個別註冊時可直接對接。

【需求備註】 公用帳號定位為「目前唯一可以控管系統與使用系統的帳密」，登入與註冊介面仍會如實建立，以便後續無縫過渡至完整多帳號權限體系。
FEATURE 03 · AI 擴充

3. 多模型整合閘道與 Spark 預備架構 (AI Model Gateway)

優先級：P3 (架構預留，待 Spark 伺服器就緒)

現階段不急於直接綁定特定模型，而是先重構系統 AI 工具的底層通訊層，建立統一的 Adapter 適配器介面。一旦公司內部 Spark 環境架設完成，即可直接無縫接入。

統一 Model Adapter

將「影像去背/修補」與「文字生成/潤飾」標準化，上層 UI 工具不綁定特定 API，透過注入不同的 Provider 進行呼叫。

Spark 專屬串接通道

預留 Spark WebSocket/REST API 規格介面，具備 Token 流式傳輸 (Stream) 與 Prompt 範本微調能力。

多模型測試切換面板

在「系統設定」中提供模型切換開關（預設 Clipdrop / 本地 vLLM / 企業 Spark），方便開發團隊隨時進行 A/B 測試。

FEATURE 01 · 旗艦技術

1. 即時多人多人協作共編引擎 (Real-time Collaboration)

優先級：P4 (旗艦攻堅，依賴專案系統)

實現多位使用者透過同一個專案連結同時進行編輯。包含即時多人游標位置 (Multiplayer Cursors)、物件編輯鎖定 (Selection Lease) 以及 衝突消解算法 (CRDTs)。

同步通訊架構 (Yjs / WebSocket)

採用業界標準 Yjs (CRDT) 或輕量級 WebSocket Relay Server，以 Delta 增量方式即時廣播物件座標、文字變更與新增圖層。

多人在線游標與頭像

在畫布上渲染不同顏色的協作者游標與名字標籤；右上角顯示當前專案在線成員清單與連線狀態指示燈。

防衝突鎖定 (Object Lease)

當 A 使用者正在選取並拖曳某個物件時，B 使用者畫面上該物件會顯示 A 的代表色外框並暫時鎖定，防止畫面互相覆蓋抽動。

03 項目升級順序與優先級評估矩陣

依據功能依賴性 (Dependency)、開發成本與使用者價值制定最佳實作先後順序

實作順序 項目名稱 優先級 技術依賴關係 (Rationale) 預估複雜度 預定版本
Step 1 4. 檔案管理 (儀表板與儲存) P0 (最先) 所有升級的基石！必須先有「專案 ID」與 IndexedDB 存檔機制，後續的多人共編與權限才有標的物可以綁定。 中等 (Medium) v1.2.0
Step 2 2. 顏色模板與主題系統 P1 (前期) 純前端 CSS/Tokens 改造。提早完成可確保後續新增的所有儀表板、帳號彈窗與協作介面自動套用多主題，避免後期二次重構。 較低 (Low) v1.3.0
Step 3 5. 角色帳號管理 (預設帳號) P2 (中期) 建立預設 Default Admin，在專案管理內注入「擁有者/建立者」標記，為多人共編的權限檢驗奠定基礎。 較低 (Low) v1.4.0
Step 4 3. 測試用其他模型 (Spark 預備) P3 (中期) 重構 AI 通訊 Adapter 介面，預留 Spark 設定欄位。等待公司 Spark 架設完成後即可接上。 中等 (Medium) v1.5.0
Step 5 1. 多人即時共編功能 P4 (旗艦) 最關鍵的重大突破！依賴專案系統與帳號狀態，導入 WebSocket/Yjs 與游標同步，作為 V2.0 正式發布的旗仗亮點。 最高 (High) v2.0.0

04 詳細工作排程與 Sprint 里程碑 (Roadmap)

以 6 個 Sprint (約 6~8 週) 為週期的敏捷式漸進交付計畫

Sprint 1 (第 1~2 週) · 專案檔案管理系統構建 預定版號: v1.2.0

建立 Project Dashboard 首頁與 IndexedDB 本機持久化

  • 實作 src/features/dashboard/ 專案儀表板視圖。
  • 建立 ProjectStorageEngine.js，實現專案新增、儲存、快照縮圖寫入 IndexedDB。
  • 在主畫面左上角新增「返回首頁」與專案切換入口，實現 Auto-Save 防抖存檔。
Sprint 2 (第 3 週) · 主題模板與顏色變換系統 預定版號: v1.3.0

實作全域 Design Tokens 與 4 款主題風格切換器

  • 重構 style.css，抽離核心 CSS 變數（工作區底色、面板色、邊框色）。
  • 於右上角新增「主題切換」選單（深色 Dark / 淺色手繪 Sketch / 專業冷灰 Pro / 復古文青）。
  • 將使用者主題偏好記憶於 LocalStorage，重新開啟自動生效。
Sprint 3 (第 4 週) · 角色帳號、登入/註冊介面與系統金鑰中心 預定版號: v1.4.0

建立登入/註冊彈窗介面、公用管理者驗證與 RBAC 介面架構

  • 實作手繪風「登入 / 註冊」切換彈窗與 Session 狀態管理。
  • 建立 src/features/auth/AuthManager.js，配置公用管理者帳密驗證。
  • 專案新增「建立者/擁有者」元資料，右上角顯示使用者頭像與角色徽章。
  • 建立「系統金鑰中心 (API Vault)」彈窗，整合儲存各項服務 API Key。
Sprint 4 (第 5 週) · AI 多模型適配器與 Spark 預備層 預定版號: v1.5.0

抽象化 AI 工具通訊層，預備對接企業 Spark 伺服器

  • 重構智慧工具為 AIProviderAdapter 統一呼叫架構。
  • 撰寫 Spark 專屬連接器 (SparkConnector.js)，支援 Endpoint 與 Token 測試。
  • 提供 AI 測試除錯控制台，可切換 Mock / Clipdrop / Spark 模式。
Sprint 5~6 (第 6~8 週) · 即時多人共編旗艦引擎 正式版號: v2.0.0 (MAJOR RELEASE)

完成 Yjs / WebSocket 協作引擎、在線游標與防衝突鎖定

  • 建立 src/features/collaboration/CollabEngine.js 廣播 Fabric 物件變更。
  • 實作畫布多色動態游標 (MultiplayerCursorOverlay) 與在線成員列表。
  • 實作物件租約鎖定機制 (Object Lease)，防止同時間選取衝突。
  • 進行高並發與網路延遲測試，驗收 V2.0 正式旗艦版本。
