# 系統需求書 (v0)

> **說明**：此文件用於記錄與使用者初步討論的需求。請在與使用者確認系統目標與功能後填寫此範本，並等待使用者確認。

## 1. 系統目標
打造一個基於 Web 的圖片與 PDF 文字編輯系統，主要用於簡報或圖文教材的後製修改。提供使用者直覺的畫布操作、自動化 OCR 辨識、無痕去背與浮水印移除功能，大幅降低圖文編修的門檻。

## 2. 核心功能清單
- **檔案處理**：支援單張圖片與多頁 PDF 的匯入與渲染，並可將編輯結果匯出為圖片、PPTX 或 PDF。
- **智慧去印與修補**：提供塗抹去印、選框去印、純色覆蓋，自動補齊背景色。
- **OCR 辨識替換**：框選範圍自動辨識文字內容，並生成可編輯的文字方塊。
- **進階去背功能**：吸色去背、截圖去背，輕鬆移除不需要的背景。
- **物件編輯**：加入與調整文字（大小、顏色、行距等）、插入圖片/Logo、加入 QR Code、插入自訂色塊。
- **狀態與進度保護**：支援復原(Undo)/重做(Redo)，並透過瀏覽器本地儲存(IndexedDB)自動暫存編輯進度，防範意外關閉。

## 3. 使用者角色與權限
- **一般使用者**：擁有完整的編輯權限，能夠上傳檔案、使用所有編修工具、以及下載匯出成品。系統目前為純前端架構，無需登入即可使用。

## 4. 系統框架初步構想
- **前端技術**：原生 HTML / JavaScript，搭配 TailwindCSS 建立現代化介面，使用 HTML5 Canvas 處理核心繪圖邏輯。
- **後端技術**：無後端（純前端 Client-side 運算）。
- **其他預計使用的技術棧**：
  - PDF.js / jsPDF：用於 PDF 檔案解析與產出。
  - PptxGenJS：用於 PPTX 檔案匯出。
  - Tesseract.js：提供瀏覽器端的 OCR 辨識能力。
  - qrcode.js：生成 QR Code。
  - IndexedDB：用於本地大容量狀態暫存。

## 5. 🌟 系統整體驗收標準 (Acceptance Criteria)
- 使用者能夠順利匯入多頁 PDF 或單張圖片，畫布渲染清晰且效能順暢。
- 具備完整還原進度能力，重新整理頁面後能載入先前的編輯狀態。
- OCR 與去印功能運作正常，不會造成瀏覽器嚴重卡頓或崩潰。
- 最終匯出的 PDF 與 PPTX 檔案格式與畫面上呈現的排版相符。
