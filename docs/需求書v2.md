# 系統需求書 (v2)

> **說明**：本版本根據使用者的補充說明更新（包含畫布比例鎖定、快捷鍵補強、QR Code 屬性調整、.env 配置，並將工具列模組進一步細化至單一檔案隔離等級）。

## 1. 系統目標
打造名為「多媒體畫布編輯器V2」的專業級 Web 影像與文件編輯平台。系統將區分為「圖片工作區」與「PPT/PDF 工作區」，提供精準的物件圖層控制、豐富的智慧去背與修補功能（串接 API）、表格建置，以及嚴格的畫布邊界限制與群組快捷操作，達到媲美專業桌面軟體的編輯體驗。

## 2. 核心功能清單

### 2.1 雙工作區模式與畫布管理
- **圖片工作區**：單頁編輯模式，右側無縮圖，上方提供「16:9」與「4:3」比例切換。
- **PPT/PDF 工作區**：多頁編輯模式，右側具備獨立縮圖介面（各頁互不影響）。支援匯入 PPT（透過 API 轉 PDF）與 PDF；即使未匯入也可手動新增多頁空白頁。上方提供「直式(A4)」與「橫式」切換。
- **畫布比例鎖定機制**：在任何工作區成功匯入檔案後，左上角的畫布比例切換按鈕將自動轉為不可調整狀態（Disabled）。
- **畫布邊界限制**：物件、圖片不可超出畫布白色範圍，邊框具備「撞牆」阻擋效果。畫布尺寸會根據匯入檔案的邊框自動貼合。
- **底圖 vs 外部圖片**：匯入的「主題/檔案」視為底圖，不可移動（除非經過一鍵去背後轉為圖層物件）；「外部圖片/Logo」則視為浮動圖層，可任意移動、縮放、調亮度及智慧去背。

### 2.2 四大左側面板（嚴格模組化）
1. **工具 (Tools)**：包含基本視圖、智慧去背修補、加入新物件。
2. **屬性 (Properties)**：動態顯示目前選取物件的參數（如文字字型/顏色/大小、圖片亮度、群組/取消群組按鈕等）。
3. **圖層 (Layers)**：可調整物件的上下層級（Z-index），並支援鎖定物件。
4. **素材庫 (Assets)**：儲存使用者自訂的圖形物件、客製化 QR Code、智慧去背產生的貼圖等，供隨時拖曳使用。

### 2.3 工具列詳細功能
- **基本視圖工具**：選取（預設）、平移、形狀（可調色）、畫筆（可調色與粗細）、放大、縮小。
- **智慧去背與修補（防呆機制：未匯入檔案前全面禁用）**：
  1. 一鍵去背。
  2. 塗抹修補：自訂畫筆粗細，串接 API 進行影像修補。
  3. 選框去背：將原圖特定區塊去背並擷取為可用貼圖。
  4. 智慧修補：根據選框範圍，自動生成符合背景的內容填補。
  5. 智慧辨識 (OCR)：框選範圍自動辨識文字，並轉換為可編輯文字方塊。
  6. 純色覆蓋：類似畫筆效果。
- **加入新物件**：
  - 新增文字。
  - 建立表格（樣式與邊框自由調整，如 Canva/Word）。
  - QR 條碼：使用者輸入網址由系統生成後，可選取圖示調整顏色與樣式，並支援存入素材庫。
  - 外部圖片/Logo。

### 2.4 進階操作與狀態保護
- **快捷鍵支援**：複製 (Ctrl+C)、貼上 (Ctrl+V)、復原 (Ctrl+Z)、重做 (Ctrl+Y)、群組 (Ctrl+G)、取消群組 (Shift+Ctrl+G)。
- **群組功能**：按住 `Shift` 點選多個物件後，可透過屬性面板或 `Ctrl+G` 進行群組化。
- **狀態與進度保護**：右上角匯入按鈕旁設置「復原」與「重做」按鈕；自動透過瀏覽器 IndexedDB 暫存進度，防範意外關閉。

## 3. 資料夾架構與規範存放點
系統採行「絕對功能隔離」，前端介面、畫布與每一項獨立工具都將拆分為獨立檔案，確保單一工具的修改絕對不會波及其他工具。

```text
src/
├── .env                   # 預留 API Key 等環境變數配置檔
├── core/                  # 核心畫布引擎與狀態管理
├── features/              # 功能模組隔離區
│   ├── workspace/         # 雙工作區管理
│   ├── thumbnails/        # 右側縮圖面板
│   ├── properties/        # 左側屬性面板
│   ├── layers/            # 左側圖層面板
│   ├── assets/            # 左側素材庫面板
│   └── tools/             # 左側工具面板 (進一步細化，每項工具單獨檔案)
│       ├── basic/
│       │   ├── SelectTool.js, BrushTool.js, ShapeTool.js ...
│       ├── smart/
│       │   ├── OCRTool.js, MagicEraserTool.js, InpaintTool.js ...
│       └── objects/
│           ├── QRCodeTool.js, TableTool.js, TextTool.js ...
├── shared/                # 共用元件與 API 通訊
└── docs/                  # ★ 系統文件存放區 (Agent 執行前後必讀)
    ├── 標準規範v0.md      # 通用的系統開發準則 (階段三產出)
    └── 需求書v2.md        # 系統需求書
```
*(備註：針對各功能的**專屬規則書**與**規格書**，會直接存放在 `src/features/[功能名稱]/` 目錄內，確保與程式碼就近綁定，方便隨時檢視與迭代。)*

## 4. 系統框架初步構想
- **前端核心**：Vite + Vanilla JS 或輕量級框架，運用 Fabric.js 處理圖層、邊界碰撞與物件群組。
- **環境變數**：使用 `.env` 檔案集中管理外部 API Keys 與配置。
- **外部依賴庫**：Fabric.js (圖層/碰撞/群組)、PDF.js、Tesseract.js、PptxGenJS。
- **後端 API（外部串接）**：PPT 轉 PDF 轉換服務 API、影像修補 API。

## 5. 🌟 系統整體驗收標準 (Acceptance Criteria)
1. **防呆與邊界**：匯入檔案後左上角比例按鈕立刻鎖定；所有物件皆不可移出白色畫布邊緣。
2. **群組與快捷操作**：Ctrl+G / Shift+Ctrl+G 及 Undo/Redo 快捷鍵與右上角按鈕皆能即時生效。
3. **QR Code 素材化**：產生的 QR Code 成功切換顏色後，能順利存入素材庫。
4. **絕對隔離架構**：工具列中的每項功能（如畫筆、OCR、QR Code）皆為獨立檔案（如 `OCRTool.js`），絕不共用同一個龐大的邏輯檔案。
