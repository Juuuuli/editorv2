# 系統需求書 (v5)

> **版本說明**：本版本為系統演進至 **v2.0.0 (即時多人協作共編引擎)** 的正式需求書。在 v1.5.0 專案網址路由化與通訊地基建設完成的基礎上，正式啟動旗艦升級，加入 Yjs 同步、多人動態游標與物件防衝突租約。

---

## 1. 系統目標
打造具備專業桌面級畫布體驗、手繪風格 UI、多工作區與本機持久化之「多媒體畫布編輯器 V2」。
本次 **v2.0.0** 旗艦升級，目標是讓專案從「單機版」正式跨入「多人連線即時共編」，支援多名使用者在同一個專案畫布中共同作業、互不干擾且資料零衝突。

---

## 2. 核心功能清單與完成狀態

### 2.1 雙工作區模式與畫布管理【已完成 ✅】
- **圖片工作區**：單頁編輯模式，支援 16:9 / 4:3 比例切換。
- **PPT/PDF 工作區**：多頁編輯模式，具備右側縮圖預覽、PDF/PPT 匯入及增刪頁。
- **畫布邊界限制**：物件嚴格限制在畫布內，具備 Canva 風格 1px 極細輔助線與 0ms 磁吸對齊。

### 2.2 專案檔案管理系統 (Project Dashboard & Storage)【已完成 ✅ · v1.2.0】
- **專案儀表板**：專案卡片網格、建立、複製、重命名、刪除、匯出/匯入 `.editorproj`。
- **IndexedDB 持久化**：高容量本機離線資料庫儲存。
- **Auto-Save 自動存檔**：800ms 防抖自動保存。

### 2.3 全域顏色模板與多主題系統 (Multi-Theme System)【已完成 ✅ · v1.3.0】
- 支援 4 款主題風格（經典手繪風 Light Sketch 預設、深色極客 Dark、專業冷灰 Pro Slate、復古文青 Pastel/Retro）。
- Design Tokens CSS Variables 與 LocalStorage 記憶。

### 2.4 角色帳號與公用權限 (Auth & Role Guard)【已完成 ✅ · v1.4.0】
- 手繪風登入/註冊彈窗。
- 公用最高管理者帳密驗證。
- **系統模型與金鑰保險箱 (API Vault · 升級版)**：
  - 三大服務分頁：AI 核心模型 (主流雲端 + vLLM/Ollama 自訂端點)、影像處理、簡報轉檔。

### 2.5 專案網址路由化與協作分享前置 (SPA Project Routing & Presence)【已完成 ✅ · v1.5.0】
- **獨立 URL 格式**：`/editorv2/?project=[PROJECT_ID]&room=[ROOM_ID]`。
- **ShareModal**：一鍵複製共編連結與權限切換。
- **Presence 色彩池**：進入專案時自動指派隨機專屬識別色彩。

### 2.6 【v2.0.0 目標】Yjs CRDT 無衝突資料同步
- **資料結構轉換**：將單純的 JSON 快照儲存，轉換為支援 Yjs 的增量同步結構 (`Y.Map`, `Y.Array`)。
- **雙向綁定 (YjsAdapter)**：攔截 Fabric.js 的修改/新增/刪除事件，即時發布到 Yjs；並監聽 Yjs 變更以更新本地畫布。
- **WebRTC/WebSocket 連線**：依賴 `CollabEngine` 處理 P2P 或中繼站的 Yjs 增量資料廣播。

### 2.7 【v2.0.0 目標】多人動態游標與身分標籤 (Multiplayer Cursors)
- **獨立游標圖層**：在畫布上層疊加 Canvas/DOM 渲染所有遠端成員的游標與名稱標籤。
- **滑順補間動畫 (LERP)**：避免網路延遲帶來的游標瞬移抖動。
- **Presence 整合**：游標顏色與使用者名稱需根據 `PresenceManager` 提供的資料即時渲染。

### 2.8 【v2.0.0 目標】物件防衝突租約 (Object Lease)
- **選取鎖定**：當 User A 點選特定物件時，該物件在其他人畫面上顯示為「鎖定狀態」（例如紅色框線或擁有者顏色框線），並設為不可選取 (`selectable: false`)。
- **釋放租約**：取消選取後解除鎖定，允許他人編輯。

## 4. 驗收標準 (Acceptance Criteria)
1. **資料同步**：多人在同一房間內，任一人移動、縮放、旋轉物件，其他人的畫面能在 200ms 內反應且不產生重影或錯位。
2. **游標廣播**：能清晰看見對方的彩色游標與名字，且滑動平滑。
3. **物件鎖定**：當一人拖曳物件時，其他人無法同時選中該物件干擾操作。
