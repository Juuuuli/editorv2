## 1. 功能概述

為了支援多樣化的 AI 模型擴充、自建 private LLM (vLLM/Ollama)、專業影像處理 (去背/修補) 與高保真 PPT 轉檔，本系統將原本簡單的金鑰欄位升級為模組化、分頁式的「**系統模型設定與金鑰保險箱 (API Vault)**」。

---

## 2. 介面與功能架構 (3 大分類 Tab)

彈窗採用左右佈局（左側分類導覽，右側動態內容面板）：

### 2.1 Tab 1：AI 核心模型 (LLM 大腦)
負責畫布上的智慧文案生成、版面解析與對話助手。
* **內建主流 (推薦)**：
  * 提供商切換：OpenAI / Anthropic。
  * 模型下拉選擇：GPT-4o、GPT-4o-mini、Claude 3.5 Sonnet。
  * API Key 輸入欄位（附帶顯示/隱藏密碼切換）。
* **自訂模型端點 (vLLM / Ollama)**：
  * 配置名稱：使用者自訂（例：公司內網 vLLM）。
  * 模型識別碼 (Model ID)：例 `meta-llama/Llama-3-8B`。
  * Base URL：支援相容 OpenAI 格式之端點（例 `https://api.your-company.com/v1`）。
  * Bearer Token：選填金鑰。

### 2.2 Tab 2：影像去背與修補 (Image Processing)
負責畫布影像的智慧去背與 Inpainting 局部修補。
* **提供商下拉選擇**：
  1. `Clipdrop API`（預設，支援去背與 Inpainting）
  2. `Photoroom API`（電商級高品質去背）
  3. `Remove.bg`（純去背）
  4. `Stable Diffusion`（自建私有伺服器）
* **影像處理 API Key 輸入**。

### 2.3 Tab 3：簡報轉檔解析 (PPT/PDF Parsing)
負責將企業上傳之 PPT/PPTX 轉換為標準 PDF 匯入畫布。
* **提供商下拉選擇**：
  1. `ConvertAPI`（目前預設雲端方案）
  2. `CloudConvert`（雲端備用方案）
  3. `Gotenberg`（LibreOffice Docker 自建方案，免費且資料不外流）
* **供應商 API Secret / 伺服器網址輸入**。

## 3. 資料結構與持久化 (Data Storage)

設定統一儲存於瀏覽器 `localStorage` 之 `EDITOR_V2_VAULT_CONFIG`：

```javascript
const defaultVaultConfig = {
    activeLlmType: 'builtin', // 'builtin' | 'custom'
    builtin: {
        provider: 'openai',
        model: 'gpt-4o',
        apiKey: ''
    },
    custom: {
        name: '',
        baseUrl: '',
        modelId: '',
        token: ''
    },
    imageProcessing: {
        provider: 'clipdrop',
        apiKey: ''
    },
    pptParsing: {
        provider: 'convertapi',
        secret: ''
    },
    updatedAt: Date.now()
};
```

---

## 4. 跨模組通訊與事件流

1. **開啟保險箱**：`EventBus.emit('VAULT:OPEN_MODAL')`
2. **儲存設定**：使用者點擊「儲存設定」➔ 寫入 `localStorage` ➔ 發送廣播 `EventBus.emit('VAULT:CONFIG_UPDATED', newConfig)`
3. **取消/關閉**：還原未儲存的暫存變更並關閉 Modal。
