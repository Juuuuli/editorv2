# 系統需求書 (v3)

> **版本說明**：本版本為系統邁向 **V2.0** 的核心需求演進版本。除保留 v2 的雙工作區、手繪風 UI 與各項獨立工具外，正式納入五大升級項目：**專案檔案管理儀表板**、**全域顏色主題模板**、**角色帳號與登入權限**、**AI 多模型整合閘道 (Spark 預備)** 以及 **即時多人協作共編引擎**。

---

## 1. 系統目標
打造名為「多媒體畫布編輯器 V2」的現代化 Web 影像與多頁文件編輯協作平台。在維持既有專業桌面級畫布操作、手繪風格視覺（.sketch UI）、雙工作區（圖片 vs PPT/PDF）及嚴格邊界物理限制的基礎上，全面擴展為**「具備專案管理儀表板、多主題切換、金鑰管理、多模型 AI 支援與即時多人共編協作」**的次世代創作系統。

---

## 2. 核心功能清單

### 2.1 雙工作區模式與畫布管理 (既有核心)
- **圖片工作區**：單頁編輯模式，支援「16:9」與「4:3」比例切換。
- **PPT/PDF 工作區**：多頁編輯模式，具備右側縮圖預覽、PDF/PPT 匯入及空白頁增刪。
- **邊界碰撞與比例鎖定**：物件嚴格受限於白色畫布內；檔案匯入後頂部比例自動鎖定。

### 2.2 四大左側面板（嚴格模組化隔離）
1. **工具 (Tools)**：基本視圖工具、智慧去背修補（OCR、一鍵去背、塗抹修補）、加入新物件（文字、表格、QR Code、圖片）。
2. **屬性 (Properties)**：選取物件時自動切換並展示樣式調整參數。
3. **圖層 (Layers)**：物件 Z-index 調序與鎖定。
4. **素材庫 (Assets)**：儲存客製圖形、QR Code、去背貼圖。

### 2.3 【新增升級】專案檔案管理系統 (Project Dashboard & Storage)
- **首頁專案儀表板**：提供類似 Canva / Figma 的專案卡片網格，包含高解析縮圖、專案名稱、修改時間。
- **專案生命週期管理**：
  - 新增空白專案（可指定尺寸比例）。
  - 複製專案副本 (Duplicate)。
  - 專案重命名 (Rename) 與刪除 (Delete)。
  - 專案匯出/匯入（`.editorproj` 檔案包）。
- **IndexedDB 本機持久化**：使用瀏覽器資料庫完整儲存專案 JSON、多頁快照與縮圖，支援離線與隨開隨載。
- **Auto-Save 自動存檔**：編輯畫布時防抖 (Debounce 800ms) 背景自動存入 IndexedDB。

### 2.4 【新增升級】全域顏色模板與多主題系統 (Multi-Theme System)
- **保留預設手繪風**：以現有經典手繪風（暖白底 + 手繪雙線邊框）為預設風格。
- **四款風格切換**：
  1. 🎨 **經典手繪風 (Light Sketch - 預設)**
  2. 🌙 **深色極客風 (Dark)**
  3. 💼 **專業專業風 (Pro Slate)**
  4. 📜 **復古文青風 (Pastel/Retro)**
- **即時切換與偏好記憶**：透過右上角選單一鍵切換，並自動將主題偏好存於 `localStorage`。

### 2.5 【新增升級】角色帳號、登入/註冊介面與公用權限 (Auth & Role Guard)
- **手繪風登入/註冊介面**：右上角提供登入入口，點擊開啟手繪風登入與註冊切換彈窗。
- **公用最高管理者帳密**：現階段預設一組公用主帳密，作為目前唯一可登入並控管/使用系統的通行憑證。
- **預留 RBAC 角色模型**：底層預先建立 Admin (擁有者)、Editor (協作者) 與 Viewer (僅檢視) 權限檢查體系，為未來全面多帳號開放鋪路。
- **系統金鑰中心 (API Vault)**：安全集中管理 Clipdrop、Spark 或其他 AI 服務的 API Keys。

### 2.6 【新增升級】AI 多模型整合閘道與 Spark 預備層 (AI Model Gateway)
- **統一通訊適配器 (`AIProviderAdapter`)**：將影像處理與文字工具與底層 API 解耦。
- **企業 Spark 連接器 (`SparkConnector`)**：預留企業內部 Spark 伺服器規格通道，支援 Stream 流式傳輸。
- **模型切換與除錯面板**：設定面板中提供 Mock / Clipdrop / Spark 模式切換。

### 2.7 【新增升級】即時多人協作共編引擎 (Real-time Collaboration)
- **通訊同步**：採用 **Yjs (CRDT)** 或輕量 WebSocket 服務廣播物件變更增量。
- **動態多人游標 (Multiplayer Cursors)**：畫布上即時顯示協作者彩色游標與名稱標籤。
- **物件租約防衝突 (Object Lease)**：選取物件時即時鎖定，避免多端同時編輯同一物件造成覆蓋。
- **在線成員清單**：右上角顯示目前專案共同編輯的成員頭像與連線狀態。

## 4. 驗收標準 (Acceptance Criteria)
1. **專案管理驗收**：能在首頁建立多個專案、重整後專案內容不丟失、可匯出與匯入專案檔案。
2. **主題切換驗收**：預設維持手繪風格，切換至 Dark / Pro 等主題後全域顏色即時變換，且重整後能自動記住。
3. **帳號權限驗收**：登入/註冊彈窗能正常開啟，使用公用管理者帳密能順利登入解鎖權限。
4. **AI 模型閘道驗收**：智慧工具底層呼叫統一走 Adapter，預留 Spark 設定欄位且可正常配置。
5. **多人共編驗收**：兩台瀏覽器開啟同一專案能即時看到彼此的游標、物件變更與選取鎖定框。
