## 1. 專案現況檢視與規範彙整 (Overview)

### 1.1 現行架構基線 (`v1.4.1` · 穩定版)
* **核心技術棧**：Vite + Vanilla JS + Fabric.js (畫布引擎) + TailwindCSS。
* **部署環境**：目前託管於 GitHub Pages（純前端靜態架構）。
* **功能狀態**：
  * 具備雙工作區模式（單頁圖片模式 vs 多頁 PDF/PPT 模式）。
  * 模組化隔離架構 (`src/features/[module]`) 與事件驅動中樞 (`EventBus.js`)。
  * 具備手繪風格 UI (`.sketch-btn`, 手繪雙線邊框)、紅色虛線選取框、視角平移連動工作板。
  * 【Sprint 1 已完成】：專案儀表板 (`v1.2.0`)、IndexedDB 本機持久化、Auto-Save 自動存檔。
  * 【Sprint 2 已完成】：4 款顏色主題切換系統 (`v1.3.0`)、全域 Design Tokens。
  * 【Sprint 3 已完成】：角色帳號管理 (`v1.4.0`)、手繪風登入/註冊彈窗、公用管理者驗證、系統金鑰保險箱 (API Vault)。
  * 【加碼已完成】：Canva 風格 1px 極細智慧參考線與 0ms 磁吸對齊 (`v1.4.1`)。
  * 具備自動化版號規範：修復 Bug 自動 Patch+1，新增功能自動 Minor+1。
* **關鍵突破挑戰**：為滿足「多人共編」，必須從純靜態擴展為 **「SPA 專案網址路由 + Broadcast/WebSocket/CRDT 即時通訊」** 混合架構。

## 2. 升級項目 · 深度技術設計 (Feature Specifications)

### 項目 4：檔案管理與專案儀表板 (Project Dashboard) —— 【狀態：已完成 ✅ · v1.2.0 · Sprint 1】
* **目標**：打造類似 **Canva / Figma** 的首頁儀表板，支援多專案並行、本機資料持久化與自動存檔。
* **版本**：`v1.2.0` (P0)
* **技術規格**：
  1. **持久化引擎 (`ProjectStorageEngine.js`)**：封裝瀏覽器原生 IndexedDB，支援上百個專案之 JSON、多頁快照、縮圖與建立/修改時間戳記。
  2. **專案首頁視圖 (`src/features/dashboard/`)**：
     * 專案卡片網格 (Grid View)，顯示高解析預覽縮圖與專案名稱。
     * 新增空白專案（可選 16:9 / 4:3 / A4 直橫式）。
     * 複製專案副本 (Duplicate)、重命名 (Rename)、刪除專案 (Delete)。
     * 匯出/匯入 `.editorproj` 專案檔（方便跨電腦傳遞）。
  3. **自動存檔機制 (Auto-Save)**：監聽 `CANVAS:DIRTY` 事件，防抖 (Debounce 800ms) 背景自動存入 IndexedDB，避免意外關閉遺失。
  4. **首頁與編輯器雙向切換**：頂部導覽列提供「返回專案首頁」與快捷切換專案入口。

---

### 項目 2：顏色模板與多風格主題切換 (Multi-Theme System) —— 【狀態：已完成 ✅ · v1.3.0 · Sprint 2】
* **目標**：保留現有手繪風格為預設，支援隨時雙向切換深色、淺色手繪、復古文青與專業冷灰主題。
* **版本**：`v1.3.0` (P1)
* **技術規格**：
  1. **Design Tokens 抽離**：將全域色彩（工作區底色、面板底色、文字色、按鈕手繪邊框色）抽離為 CSS Variables。
  2. **四套主題調色盤**：
     * 🎨 **經典手繪風 (Light Sketch - 預設)**：現行風格，溫暖手繪雙線邊框與鵝黃暖白底。
     * 🌙 **深色極客風 (Dark)**：深灰黑底 (`#0f172a`)，發光霓虹微微點綴，適合夜間。
     * 💼 **專業專業風 (Pro Slate)**：冷灰極簡介面（類似 Figma / Photoshop）。
     * 📜 **復古文青風 (Pastel/Retro)**：莫蘭迪粉彩與米白格紋。
  3. **狀態記憶**：將主題偏好存於 `localStorage`，開機自動套用。

---

### 項目 5：角色帳號、登入/註冊介面與公用權限控管 (Role & Account Guard) —— 【狀態：已完成 ✅ · v1.4.0 · Sprint 3】
* **目標**：提供標準登入/註冊手繪風介面，現階段提供一組「公用最高管理者帳密」作為全功能通行證，底層預留完整 RBAC 角色模型。
* **版本**：`v1.4.0` (P2)
* **技術規格**：
  1. **登入 / 註冊 UI**：右上角新增使用者頭像與登入入口，支援手繪風登入/註冊切換彈窗。
  2. **公用管理者帳密 (Master Credential)**：配置一組公用主帳密，供團隊所有成員登入並控管系統所有功能。
  3. **RBAC 角色擴充層**：預留 Admin (擁有者)、Editor (協作者)、Viewer (僅檢視) 三大角色定義，未來多帳號上線時可直接對接。
  4. **系統金鑰保險箱 (API Vault)**：提供統一的金鑰管理彈窗，安全儲存 Clipdrop、Spark 或其他 AI 金鑰於本地。

---

### 項目 6：專案網址路由化與共編前置作業 (Project Routing & Collab Prep) —— 【狀態：即將進行 🚀 · v1.5.0 · Sprint 4】
* **目標**：實現前端專案獨立網址路由 (SPA Routing)、Deep Linking 直通專案，並於使用者選單中新增「專案協作與分享」彈窗與單機測試通道。
* **預定版本**：`v1.5.0` (P3)
* **技術規格**：
  1. **專案路由管理器 (`src/core/ProjectRouter.js`)**：採用 `history.pushState` 實現 `?project=[ID]` 獨立網址與瀏覽器上一頁/下一頁原生歷史切換。
  2. **分享與協作彈窗 (`src/features/collaboration/ShareModal.js`)**：右上角使用者選單中點擊開啟手繪風 Modal，提供一鍵複製專案共編網址、6 位數房間碼 (PIN) 與權限設定。
  3. **協作者 Presence 標識 (`PresenceManager.js`)**：為各使用者分配隨機專屬識別色彩與名稱。
  4. **本機廣播測試通道 (`CollabChannel.js`)**：透過 `BroadcastChannel` 支援單機跨分頁即時測試。

---

### 項目 3：多模型整合閘道與 Spark 預備架構 (AI Model Gateway) —— 【狀態：規劃中 ⏳ · v1.6.0 · Sprint 5】
* **目標**：抽象化 AI 工具通訊層，預留企業內部 Spark (星火/專屬伺服器) 連接器，待伺服器就緒後一鍵對接。
* **預定版本**：`v1.6.0` (P4)
* **技術規格**：
  1. **統一適配器介面 (`AIProviderAdapter.js`)**：智慧去背、影像修補、文字潤飾等功能不與特定 API 綁定，透過 Provider 注入呼叫。
  2. **Spark 專屬連接器 (`SparkConnector.js`)**：預留 Spark WebSocket/REST 規格接口與 Token 流式處理。
  3. **A/B 測試除錯控制台**：在設定面板中提供 Mock / Clipdrop / Spark 即時切換測試。

---

### 項目 1：即時多人協作共編引擎 (Real-time Collaboration) —— 【狀態：旗艦目標 🏆 · v2.0.0 · Sprint 6~7】
* **目標**：多位使用者透過同一個專案連結同時在線編輯，具備即時在線游標、物件租約鎖定與防衝突同步。
* **預定版本**：`v2.0.0` (P5 · 旗艦技術)
* **技術規格**：
  1. **同步通訊層 (`CollabEngine.js`)**：採用 **Yjs (CRDT)** 或 WebSocket Relay Server 廣播 Fabric 物件增量變更。
  2. **多人游標與成員列表 (`MultiplayerCursorOverlay.js`)**：畫布即時渲染各協作者彩色游標與名稱標籤；右上角顯示在線成員。
  3. **物件租約鎖定 (Object Lease)**：當 A 選取物件時，B 畫面上該物件顯示鎖定框，防止同時修改衝突。
