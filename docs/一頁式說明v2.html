多媒體畫布編輯器V2 Blueprint

極致解耦工具列、智慧修補 API、嚴謹邊界與全圖層管理的編輯平台

動機與目標效益

當前痛點

傳統網頁編輯器程式碼往往混雜難以維護，且無法嚴格管控畫布邊界，缺乏針對單圖與多頁文件（PPT/PDF）的專屬防呆工作流。

預期效益 (Metrics)

完美切換雙工作區，透過「絕對功能隔離」的程式碼模組化、精準圖層與群組快捷操作，打造順暢不卡頓的專業體驗。

使用者角色 (User Personas)

專業美編人員

需求： 精準操作圖層、Ctrl+G 群組化，將去背完成的圖片或變色 QR Code 存入素材庫。

簡報製作者

需求： 匯入 PPT/PDF 排版，一旦匯入自動鎖定左上角比例選項以防誤觸，保障排版一致性。

開發工程師

需求： 確保每個工具(如 OCR、畫筆)皆拆分為獨立檔案，不牽一髮動全身，並有 .env 統一管理 API Key。

一般使用者

需求： 享受直覺的右上角 Undo/Redo 按鈕、快捷鍵操作與防呆的工具列設計，無痛上手。

核心功能與操作動線 (Features & User Journey)

1. 物理畫布與防呆機制

畫布具備邊界碰撞限制，匯入檔案後比例自動鎖定；未匯入檔案前，智慧去背等進階工具強制鎖定。

2. 獨立拆分的控制面板

細化至檔案層級的左側面板：每項工具皆有獨立 JS 檔，搭配屬性、圖層與素材庫，邏輯互不干擾。

3. 快捷操作與 API 串接

支援 Shift 多選群組 (Ctrl+G)，右上角 Undo/Redo，並透過 .env 串接塗抹修補與 PPT 轉換 API。

核心技術選型

前端: Vite + Vanilla JS 模組 UI: TailwindCSS 渲染引擎: Fabric.js 儲存: IndexedDB

開發里程碑與時程 (Roadmap)

Phase 1 (Week 1) 工具解耦與畫布建立
確認系統需求書 v2 變更
建置拆分至檔案級別的 Vite 資料夾架構
實作雙工作區與畫布比例鎖定防呆
Phase 2 (Week 2-3) 獨立模組與快捷 API
開發獨立檔案工具 (QR Code, 表格, 修補等)
Shift 多選、Ctrl+G 群組及右上角 Undo/Redo
配置 .env 並串接修圖與轉換 API
Phase 3 (Week 4) 驗收測試與防禦審查
畫布碰撞與智慧工具預設禁用防呆測試
程式碼解耦審查，確保無胖檔案
效能調校與正式上線
