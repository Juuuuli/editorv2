Web 圖片文字編輯系統 Blueprint

專業的瀏覽器端圖片與 PDF 編輯神器，輕鬆搞定去印、OCR 與簡報修改

動機與目標效益

當前痛點

現有軟體操作門檻高，修改單張圖片或 PDF 文字常需動用 Photoshop 等專業工具，耗時且無法批次處理簡報檔。

預期效益 (Metrics)

免安裝直接在瀏覽器運行，結合 OCR 與智慧修補，節省 90% 以上的圖文修改時間，並確保進度不遺失。

使用者角色 (User Personas)

行銷企劃人員

需求： 快速修改海報或簡報圖檔中的活動文字、替換 QR Code 與 Logo

教材編輯者

需求： 匯入多頁 PDF 教材，快速去浮水印、辨識文字並重新排版，最後匯出 PPTX

社群小編

需求： 利用吸色去背、純色覆蓋與圖層功能，快速製作梗圖或貼文素材

一般使用者

需求： 免註冊登入，隨開即用，不怕修改進度遺失的自動存檔功能

核心功能與操作動線 (Features & User Journey)

1. 智慧去印與 OCR 辨識

提供塗抹與選框去印功能自動修補背景，並結合 Tesseract.js 實現框選文字自動轉為可編輯文字方塊。

2. 豐富的物件編輯系統

支援插入自訂文字（字距、行距、字重）、圖片/Logo、QR Code 與純色色塊，並可自由拖曳縮放。

3. 跨格式匯出與進度保護

支援匯入圖片與多頁 PDF，編輯後可無縫匯出為 PNG, PDF 或 PPTX，同時具備 IndexedDB 自動暫存功能。
