# 滑鼠操作與視圖控制功能規格書

## 1. 功能概述
為了提升編輯器在各種尺寸螢幕與不同解析度專案下的操作體驗，系統導入了高自由度的滑鼠視圖控制功能。使用者能夠透過直覺的滑鼠操作（滾輪、快捷鍵結合拖曳）在畫布上進行精確的平移 (Pan) 與縮放 (Zoom)，而不受限於工具列當前選擇的工具模式。

## 2. 操作說明與規則

### 2.1 滑鼠滾輪縮放 (Mouse Wheel Zooming)
- **觸發方式**：在畫布範圍內，上下滾動滑鼠滾輪。
- **操作邏輯**：
  - 向上滾動 (Scroll Up)：放大畫布。
  - 向下滾動 (Scroll Down)：縮小畫布。
  - **游標對齊**：縮放動作會以「目前滑鼠游標所在的座標點」為中心進行放大與縮小，讓使用者能直覺地放大檢視特定細節。
- **極限保護**：
  - 最大放大倍率限制為 20 倍。
  - 最小縮小倍率限制為 0.05 倍 (避免畫布小到完全看不見)。
- **無干擾設計**：在畫布區域內滾動滾輪時，系統會自動攔截瀏覽器的原生捲軸行為 (Prevent Default)，避免整個網頁跟著上下跳動。

### 2.2 快捷平移 (Quick Panning)
- **觸發方式**：
  1. 按住 **滑鼠中鍵 (Middle Mouse Button / Scroll Wheel Button)** 不放，拖曳滑鼠。
  2. 按住 **Alt 鍵** 不放，同時按住 **滑鼠左鍵** 拖曳滑鼠。
- **操作邏輯**：
  - 無論使用者當前選擇的是什麼工具 (例如：畫筆、選取、形狀)，只要觸發快捷平移指令，滑鼠動作即會暫時被覆寫為「平移視圖」。
  - 釋放按鍵後，即自動恢復原本的工具狀態。
- **視覺回饋**：
  - 平移時畫布上的網格背景 (Grid) 會跟著移動，提供使用者明確的空間與方向感 (2.5D 立體視差感)。

## 3. 技術實作說明
- 全局事件綁定於 `CanvasEngine.js` 中的 `bindEvents` 方法。
- 使用 `mouse:wheel` 監聽滾輪事件，利用 `evt.deltaY` 換算成 `zoom` 倍率，並呼叫 Fabric.js 的 `zoomToPoint` 實現對齊游標縮放。
- 在 `mouse:down` 事件中透過判斷 `evt.button === 1` 或 `evt.altKey` 動態切換 `isDraggingViewport` 狀態，達成無縫跨工具平移。
