# 畫布輔助功能 (Canvas Auxiliary Features) 規格書

## 1. 功能概述
本模組提供編輯器於物件排版與文件匯入時的各項智慧輔助能力，包含兩大核心子功能：
1. **自動吸附與智慧參考線 (Canva-style Precision Smart Guides)**：於物件拖曳移動時，自動偵測畫布邊界、中心線與其他圖元邊界，提供磁吸對齊與即時極細 1px 向量輔助線，滑鼠放開或移開時 0ms 立即消失無殘留。
2. **高解析背景預渲染 (Retina 2x High-Resolution Pre-renderer)**：於 PDF / PPTX 文件匯入時，動態提供 Retina 2.0x 超高解析度底板背景渲染與 0.5x 輕量化縮圖生成。

---

## 2. UI/UX 介面規範與設定持久化

### 2.1 設定位置
位於系統右上方最高管理／使用者設定選單中之 **「系統與外觀設定」 (System & Appearance Settings) ➔ 「畫布輔助」 (Canvas Auxiliary)** 分頁。

### 2.2 設定項目與開關
| 設定項名稱 | 預設狀態 | LocalStorage 鍵值 | 說明 |
| :--- | :--- | :--- | :--- |
| **自動吸附與智慧參考線** | 啟用 (`true`) | `editor_smart_guides` | 物件移動時自動對齊畫布邊緣與其他圖元中心 |
| **高解析背景預渲染** | 啟用 (`true`) | `editor_retina_render` | PDF/PPT 匯入時自動產生 Retina 2x 高解析背景 |

### 2.3 即時響應事件 (EventBus)
* `SETTINGS:SMART_GUIDES_CHANGED`：傳遞 `{ enabled: boolean }`，由 `SmartGuides` 模組訂閱並即時切換狀態。
* `SETTINGS:RETINA_RENDER_CHANGED`：傳遞 `{ enabled: boolean }`，寫入 LocalStorage 並供後續匯入時讀取。

## 3. 模組架構與代碼隔離 (Architecture)

為落實模組化與高內聚低耦合原則，所有相關代碼獨立收納於專屬目錄：

```
src/features/canvas_auxiliary/
├── SmartGuides.js       # Canva 風格智慧參考線與吸附運算引擎 (頂層 1px 直繪)
├── RetinaRenderer.js    # Retina 2x 高解析預渲染工具
└── index.js             # 模組統一出口
```

## 4. 自動吸附與智慧參考線技術規範 (Smart Guides)

### 4.1 吸附判定演算法
當使用者在畫布上拖曳任意非底板圖元時，系統即時計算目標物件與潛在對齊點之距離：

1. **吸附目標 (Snap Targets)**：
   * **畫布邊界與中心**：左邊緣 (`0`)、水平中心 (`width / 2`)、右邊緣 (`width`)、頂部 (`0`)、垂直中心 (`height / 2`)、底部 (`height`)。
   * **其他可見圖元**：圖元之 Left、CenterX、Right、Top、CenterY、Bottom。
2. **螢幕動態閥值 (Dynamic Screen Threshold)**：
   $$\text{Threshold} = \frac{10\text{px}}{\text{Canvas Zoom}}$$
   確保無論使用者放大或縮小畫布，皆維持舒適自然的 10 像素吸附手感。
3. **多座標系統相容**：
   自動適配並標準化 Fabric 物件的 `originX` (`left` / `center` / `right`) 與 `originY` (`top` / `center` / `bottom`)，杜絕座標跳動。

### 4.2 Canva 頂層直繪架構 (Direct Canvas Selection Layer)
* **渲染圖層**：直接在 Fabric 最頂層 `contextTop` (與選取控制框同層) 直繪，100% 絕對可見且零遮蔽問題。
* **視覺風格 (Canva Standard)**：
  * **極細 1px 實線**：使用 `Math.round(val) + 0.5` 次像素校正，畫布基準線為經典洋紅 (`#e00070`)，圖元對齊為科技青藍 (`#00c4cc`)。
  * **微型精緻錨點**：軸心處繪製 $r = 3.5\text{px}$ 實心圓點帶 1.5px 白色外框。
  * **無遮擋乾淨介面**：不使用厚重黑框文字標籤或大面積模糊光暈，保持版面清爽。
* **即時生命週期**：放開滑鼠 (`mouse:up`)、移動結束 (`object:modified`) 或移出對齊區間時，**0ms 立即清除**，不留任何延遲殘影。

## 5. 高解析背景預渲染技術規範 (Retina Pre-renderer)

### 5.1 渲染管線
* **高解析畫布底板**：
  * 依據 `RetinaRenderer.isRetinaEnabled()` 設定決定縮放比（啟用時 `scale = 2.0`，關閉時 `scale = 1.0`）。
  * 透過 PDF.js API 使用原生 2D Canvas 離屏渲染，匯出無失真 PNG DataURL，保證 Retina 螢幕與高倍率放大時清晰銳利。
* **輕量化縮圖**：
  * 固定以 `scale = 0.5` 進行離屏採樣，匯出品質為 `0.8` 的 JPEG DataURL，有效節省 80% 記憶體佔用與加速側邊欄縮圖載入。

### 5.2 呼叫整合端點
* `FileImportManager.js`：檔案匯入模組。
* `DashboardManager.js`：專案儀表板與範本載入模組。
