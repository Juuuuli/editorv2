# 系統需求書 (v4)

> **版本說明**：本版本為系統演進至 **v1.5.0 (專案網址路由化與多人共編前置作業)** 的正式需求書。確立了在邁向 **v2.0.0 完整多人即時協作** 之前，必須完成的「SPA 前端專案路由 (Deep Linking)」、「右上角分享與協作中心」、「協作者 Presence 身分識別」以及「單機跨分頁測試廣播通道」。

---

## 1. 系統目標
打造具備專業桌面級畫布體驗、手繪風格 UI、多工作區與本機持久化之「多媒體畫布編輯器 V2」。在 v1.4.1（專案儀表板、多主題、帳號權限、智慧輔助線）的堅實基礎上，推進至 **v1.5.0**：賦予每一個專案唯一的 URL 路由，提供右上角協作分享彈窗，為 v2.0.0 多人即時共編架構打下最完整的通訊與路由地基。

---

## 2. 核心功能清單與完成狀態

### 2.1 雙工作區模式與畫布管理【已完成 ✅】
- **圖片工作區**：單頁編輯模式，支援 16:9 / 4:3 比例切換。
- **PPT/PDF 工作區**：多頁編輯模式，具備右側縮圖預覽、PDF/PPT 匯入及增刪頁。
- **畫布邊界限制**：物件嚴格限制在畫布內，具備 Canva 風格 1px 極細輔助線與 0ms 磁吸對齊。

### 2.2 專案檔案管理系統 (Project Dashboard & Storage)【已完成 ✅ · v1.2.0】
- **專案儀表板**：專案卡片網格、建立、複製、重命名、刪除、匯出/匯入 `.editorproj`。
- **IndexedDB 持久化**：高容量本機離線資料庫儲存。
- **Auto-Save 自動存檔**：800ms 防抖自動保存。

### 2.3 全域顏色模板與多主題系統 (Multi-Theme System)【已完成 ✅ · v1.3.0】
- 支援 4 款主題風格（經典手繪風 Light Sketch 預設、深色極客 Dark、專業冷灰 Pro Slate、復古文青 Pastel/Retro）。
- Design Tokens CSS Variables 與 LocalStorage 記憶。

### 2.4 角色帳號與公用權限 (Auth & Role Guard)【已完成 ✅ · v1.4.0】
- 手繪風登入/註冊彈窗。
- 公用最高管理者帳密驗證。
- 系統金鑰保險箱 (API Vault)。

### 2.5 【v1.5.0 目標】專案網址路由化 (SPA Project Routing)
- **獨立 URL 格式**：`/editorv2/?project=[PROJECT_ID]` 與 `/editorv2/?project=[PROJECT_ID]&room=[ROOM_ID]`。
- **Deep Linking 直通**：網址直接貼入瀏覽器即可載入並直達該專案。
- **Popstate 歷史切換**：點擊瀏覽器上一頁/下一頁按鈕流暢往返儀表板與編輯器。

### 2.6 【v1.5.0 目標】右上角專案協作與分享中心 (ShareModal)
- **進入點收納**：整合於右上角使用者帳號下拉選單中。
- **一鍵複製共編連結**：生成完整 URL 並複製至剪貼簿。
- **6 位數房間邀請碼 (PIN)**：便於跨裝置輸入。
- **權限切換**：支援「可編輯 (Editor)」與「僅檢視 (Viewer)」。

### 2.7 【v1.5.0 目標】協作者 Presence 標識與單機測試通道
- **Presence 色彩池**：進入專案時自動指派隨機專屬識別色彩。
- **BroadcastChannel 單機雙分頁測試**：無需後端伺服器，可在本機開啟一般分頁與無痕分頁直接驗證跨視窗狀態感知。

### 2.8 【v1.6.0 規劃】AI 多模型整合閘道 (AI Model Gateway)
- 統一通訊適配器 (`AIProviderAdapter`)。
- 企業 Spark 專屬連接器與 A/B 測試除錯控制台。

### 2.9 【v2.0.0 旗艦】即時多人協作共編引擎 (Real-time Collaboration)
- Yjs CRDT / WebSocket 增量變更廣播。
- 多人動態游標與物件防衝突租約 (Object Lease)。

## 4. 驗收標準 (Acceptance Criteria)
1. **路由驗收**：開啟專案時網址正確變更為 `?project=xxx`，刷新不丟失，按上一頁能返回儀表板。
2. **分享彈窗驗收**：點擊右上角「專案協作與分享」彈出符合手繪風格之彈窗，能成功複製帶房間碼之 URL。
3. **Presence 驗收**：開啟兩個分頁時，能透過 BroadcastChannel 互相感知在線協作者的存在。
4. **規範與隔離驗收**：新增代碼皆位於 `src/features/collaboration/` 與 `src/core/ProjectRouter.js`，無跨模組強耦合。
