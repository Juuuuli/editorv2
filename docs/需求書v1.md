# 系統需求書 (v1)

> **說明**：本版本根據使用者提供的介面圖與 16 點詳細需求進行大幅更新，定義了「多媒體畫布編輯器V2」的詳細規格。

## 1. 系統目標
打造名為「多媒體畫布編輯器V2」的專業級 Web 影像與文件編輯平台。系統將區分為「圖片工作區」與「PPT/PDF 工作區」，提供精準的物件圖層控制、豐富的智慧去背與修補功能（串接 API）、表格建置，以及嚴格的畫布邊界限制與群組快捷操作，達到媲美專業桌面軟體的編輯體驗。

## 2. 核心功能清單

### 2.1 雙工作區模式與畫布管理
- **圖片工作區**：單頁編輯模式，右側無縮圖，上方提供「16:9」與「4:3」比例切換。
- **PPT/PDF 工作區**：多頁編輯模式，右側具備獨立縮圖介面（各頁互不影響）。支援匯入 PPT（透過 API 轉 PDF）與 PDF；即使未匯入也可手動新增多頁空白頁。上方提供「直式(A4)」與「橫式」切換。
- **畫布邊界限制**：物件、圖片不可超出畫布白色範圍，邊框具備「撞牆」阻擋效果。畫布尺寸會根據匯入檔案的邊框自動貼合。
- **底圖 vs 外部圖片**：匯入的「主題/檔案」視為底圖，不可移動（除非經過一鍵去背後轉為圖層物件），但可對其進行各種去背/修補；「外部圖片/Logo」則視為浮動圖層，可任意移動、縮放、調亮度及智慧去背。

### 2.2 四大左側面板（嚴格模組化）
1. **工具 (Tools)**：包含基本視圖、智慧去背修補、加入新物件。
2. **屬性 (Properties)**：動態顯示目前選取物件的參數（如文字字型/顏色/大小、圖片亮度、群組/取消群組按鈕等）。
3. **圖層 (Layers)**：可調整物件的上下層級（Z-index），並支援鎖定物件。
4. **素材庫 (Assets)**：儲存使用者自訂的圖形物件、智慧去背產生的貼圖等，供隨時拖曳使用。

### 2.3 工具列詳細功能
- **基本視圖工具**：選取（預設）、平移、形狀（可調色）、畫筆（可調色與粗細）、放大、縮小。
- **智慧去背與修補（防呆機制：未匯入檔案前全面禁用）**：
  1. 一鍵去背。
  2. 塗抹修補：自訂畫筆粗細，串接 API 進行影像修補。
  3. 選框去背：將原圖特定區塊去背並擷取為可用貼圖。
  4. 智慧修補：根據選框範圍，自動生成符合背景的內容填補。
  5. 智慧辨識 (OCR)：框選範圍自動辨識文字，並轉換為可編輯文字方塊。
  6. 純色覆蓋：類似畫筆效果。
  *（註：所有「選框」操作均直接透過滑鼠左鍵拖曳框選）*
- **加入新物件**：新增文字、建立表格（樣式與邊框自由調整，如 Canva/Word）、QR 條碼、外部圖片/Logo。

### 2.4 進階操作與狀態保護
- **快捷鍵支援**：複製 (Ctrl+C)、貼上 (Ctrl+V)、復原 (Ctrl+Z)、重做 (Ctrl+Y)、群組操作等。
- **群組功能**：按住 `Shift` 點選多個物件後，可透過屬性面板或快捷鍵進行「組成群組 / 取消群組」。
- **狀態與進度保護**：自動透過瀏覽器 IndexedDB 暫存進度，防範意外關閉。

## 3. 資料夾架構
系統採行「絕對功能隔離 (Feature-based Isolation)」原則，前端介面、畫布、右側縮圖與左側功能必須徹底拆分至不同檔案。初步規劃架構如下：

```text
src/
├── core/                  # 核心畫布引擎與 IndexedDB 狀態管理
│   ├── CanvasEngine.js    # 畫布邊界限制、縮放、底圖邏輯
│   ├── HistoryManager.js  # Undo/Redo 管理
│   └── StorageManager.js  # IndexedDB 存取
├── features/              # 功能模組隔離區
│   ├── workspace/         # 雙工作區管理 (Image vs PPT/PDF)
│   ├── thumbnails/        # 右側縮圖面板 (僅限 PPT/PDF 模式)
│   ├── properties/        # 左側屬性面板 (動態參數綁定)
│   ├── layers/            # 左側圖層面板 (Z-index, 鎖定)
│   ├── assets/            # 左側素材庫面板
│   └── tools/             # 左側工具面板 (細分為以下子模組)
│       ├── BasicTools.js  # 選取、平移、形狀、畫筆、縮放
│       ├── SmartTools.js  # 一鍵去背、塗抹、選框、智慧修補、OCR、純色覆蓋 (含 API 串接)
│       └── Objects.js     # 文字、表格、QR Code、外部圖片
├── shared/                # 共用元件與 UI (Tailwind 設定等)
│   ├── KeyboardShortcuts.js # 快捷鍵與群組邏輯 (Shift 多選)
│   └── APIClient.js       # PPT轉PDF API、智慧修補 API 通訊模組
└── index.html             # 系統入口
```

## 4. 系統框架初步構想
- **前端核心**：純原生 JavaScript 或輕量級框架（建議導入 Vite 進行模組化建置），全面運用 HTML5 Canvas 或圖形渲染庫（如 Fabric.js）處理圖層、邊界碰撞與物件群組。
- **UI 樣式**：TailwindCSS，確保介面高度客製化，還原使用者提供的設計圖。
- **外部依賴庫**：
  - Fabric.js / Konva.js：負責強大的 Canvas 圖層管理、碰撞偵測、多選群組。
  - PDF.js：解析 PDF。
  - Tesseract.js：前端 OCR 辨識。
  - PptxGenJS：匯出功能。
- **後端 API（外部串接）**：
  - PPT 轉 PDF 轉換服務 API。
  - 影像塗抹與智慧修補 API（如第三方修圖 API）。

## 5. 🌟 系統整體驗收標準 (Acceptance Criteria)
1. **介面與工作區**：標題正確顯示「多媒體畫布編輯器V2」，並且能完美切換「圖片」與「PPT/PDF」雙工作區，頂部比例按鈕隨工作區正確切換並生效。
2. **邊界物理限制**：不論是文字、表格、外部圖片，在拖曳時觸碰畫布邊緣必須有「撞牆」停止的效果，絕對無法移出白色畫布外。
3. **智慧工具鎖定**：在未匯入任何檔案前，左側「智慧去背與修補」區塊的按鈕皆呈現 Disable 狀態，點擊無效。
4. **群組與快捷鍵**：可順暢按住 Shift 多選物件，並成功群組化，群組後的物件可一起移動並受邊界限制；Ctrl+C/V/Z/Y 皆能正常作用。
5. **模組化驗證**：檢視原始碼時，左側四大面板、畫布核心與右側縮圖必須各自位於獨立的檔案中，不可有單一檔案過於龐大混合邏輯。
