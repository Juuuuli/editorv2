# 畫布比例切換功能 (Canvas Aspect Ratio Switching) 規格書

## 1. 功能概述
在編輯器的上方工具列中，提供快捷按鈕供使用者切換畫布的長寬比例。此功能會依照當下選擇的「工作區模式（圖片 / PPT/PDF）」動態切換顯示不同的比例選項，並在成功匯入檔案後啟動自動鎖定機制，防止後續因為誤觸而破壞已匯入檔案的比例。

## 2. UI/UX 介面規範

### 2.1 圖片工作區 (Image Workspace)
- **顯示條件**：預設進入時，或切換至「圖片」頁籤時顯示。
- **選項內容**：
  - `16:9` (預設啟用)
  - `4:3`
- **視覺樣式**：
  - 群組背景色：`bg-indigo-50`
  - 選取狀態 (Active)：文字顯示深藍色 (`text-indigo-700`)
  - 未選取狀態 (Inactive)：文字顯示灰色 (`text-slate-500`)

### 2.2 PPT/PDF 工作區 (PPT/PDF Workspace)
- **顯示條件**：切換至「簡報/PDF」頁籤時顯示。
- **選項內容**：
  - `橫式` (Landscape)
  - `直式` (Portrait - 預設啟用)
- **視覺樣式**：
  - 群組背景色：`bg-slate-50`
  - 選取狀態 (Active)：文字顯示深藍色 (`text-indigo-700`)
  - 未選取狀態 (Inactive)：文字顯示灰色 (`text-slate-500`)

## 3. 系統運作邏輯

### 3.1 尺寸對應表 (Canvas Resolution)
當點擊比例按鈕時，底層畫布 (Artboard) 將依照以下實體解析度自動重新調整寬高 (基於常見 96 DPI 標準)：
- **16:9**： `1920 x 1080` (Full HD 標準螢幕比例)
- **4:3**： `1440 x 1080` (傳統螢幕/相機比例)
- **橫式**： `1123 x 794` (A4 橫向)
- **直式**： `794 x 1123` (A4 直向)

### 3.2 畫面自動貼合 (Zoom to Fit)
當使用者點選任何一個比例切換按鈕，觸發底板尺寸變更 (`resizeArtboard`) 後，系統會自動呼叫 `fitToScreen()` 演算法，根據使用者當下瀏覽器視窗的大小，自動運算最佳縮放比，讓整塊新比例的畫布完整、置中地呈現在畫面中，無須手動捲動。

### 3.3 自動鎖定防呆機制 (Lock Mechanism)
為避免使用者在匯入具備特定比例的圖檔或 PDF 後，因為誤觸比例按鈕導致畫布變形或裁切不當，實作了防呆鎖定機制：
- **觸發條件**：監聽全域事件 `FILE:IMPORTED`，只要系統完成任意檔案匯入，即觸發鎖定。
- **鎖定狀態**：
  - 介面變化：所有比例切換按鈕的透明度降至 `0.5`，並將滑鼠游標更改為 `not-allowed` 禁用狀態。
  - 邏輯阻斷：無視後續所有的按鈕 Click 事件，確保畫布大小鎖定在與該匯入檔案完全貼合的狀態。

## 4. 模組化實作架構
功能代碼完全隔離至獨立的模組類別 `RatioManager.js`：
- `RatioManager` 於系統初始化階段 (`main.js`) 實例化。
- 透過依賴注入傳遞 `CanvasEngine` 實例與 `EventBus`，實現解耦。
- 自行訂閱 `WORKSPACE:MODE_CHANGED` 以切換 UI。
- 自行訂閱 `FILE:IMPORTED` 執行鎖定保護。
