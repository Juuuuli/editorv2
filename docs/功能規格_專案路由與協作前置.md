# 功能規格書：專案網址路由化與多人共編前置作業 (Project Routing & Collaboration Gateway)

## 1. 功能概述
本規格定義系統在邁向 **V2.0 即時多人協作** 之前的兩大核心基礎設施：
1. **前端專案網址路由 (URL-based Project Routing)**：每個專案具備唯一且標準的 URL Query 參數（`?project=proj_xxx`），支援直通載入 (Deep Linking)、加入書籤與瀏覽器上一頁/下一頁原生歷史切換。
2. **專案分享與協作前置系統 (Share & Collaboration Modal)**：於右上角使用者選單中新增「專案協作與分享」入口，提供一鍵複製專案共編邀請網址、6 位數房間邀請碼、權限設定與協作者 Presence 標識。

---

## 2. 前端路由技術規範 (ProjectRouter)

### 2.1 網址格式規範
* **專案首頁儀表板**：`/editorv2/`
* **開啟指定專案**：`/editorv2/?project=[PROJECT_ID]`
* **帶房間號之協作專案**：`/editorv2/?project=[PROJECT_ID]&room=[ROOM_ID]`

### 2.2 路由生命週期
1. **開機解析 (Boot & Deep Linking)**：
   - 頁面載入時讀取 `window.location.search`。
   - 若含有 `project` 參數，自動調用 `ProjectStorageEngine.getProject(id)` 載入專案並進入編輯器；若找不到或無參數，則維持儀表板視圖。
2. **路由狀態推送 (PushState)**：
   - 於儀表板點選專案進入時：調用 `history.pushState(null, '', '?project=' + id)`。
   - 於編輯器點擊返回儀表板時：調用 `history.pushState(null, '', window.location.pathname)`。
3. **歷史堆疊監聽 (Popstate)**：
   - 監聽 `window.addEventListener('popstate')`，點擊瀏覽器返回鍵時自動切換視圖與同步狀態。

---

## 3. 分享與協作中心規範 (Share & Collaboration Modal)

### 3.1 進入點
* 位於右上角使用者頭像下拉選單中之 **「🔗 專案協作與分享」 (Share & Collaborate)**。

### 3.2 彈窗內容
1. **專案連結複製區**：
   - 顯示當前專案完整 URL（含 `room` 參數）。
   - 點擊「複製連結」自動寫入剪貼簿並彈出 Toast 提示。
2. **房間號 (Room PIN)**：
   - 提供 6 位數房間碼（例如 `892-140`），方便跨裝置口頭輸入或 P2P 配對。
3. **權限設定 (Role Permission)**：
   - ✏️ **可編輯 (Editor)**：具備畫布編輯與物件同步權限。
   - 👁️ **僅檢視 (Viewer)**：簡報模式，強制唯讀。
4. **協作者 Presence 標識**：
   - 顯示當前使用者專屬隨機識別色與名稱。

## 4. 模組架構與目錄清單
```
src/
├── core/
│   └── ProjectRouter.js          # SPA 專案路由管理器
├── features/
│   └── collaboration/            # 多人共編模組目錄
│       ├── ShareModal.js         # 手繪風分享與協作彈窗
│       ├── PresenceManager.js    # 協作者身分與色彩管理
│       ├── CollabChannel.js      # 本機 BroadcastChannel 測試通道
│       └── index.js              # 模組統一出口
```

---

## 5. 驗收標準 (Acceptance Criteria)
1. 進入專案時網址正確反映 `?project=...`。
2. 複製該網址至新分頁能直接開啟該專案。
3. 點擊瀏覽器返回鍵可返回儀表板。
4. 點擊「專案協作與分享」能正常複製邀請連結與房間碼。
5. 視覺完整適配手繪雙線邊框與 4 款主題風格。
